# 0014. Карты: MapLibre, векторные тайлы OSM по URL стиля из env, коридор гонки на карточке

- Статус: Accepted
- Дата: 2026-10-27
- Задача: `docs/tasks/2026-10-27-maps-01-route-corridor`

Принят 2026-10-27: провайдер на старте — OpenFreeMap (выбор пользователя).

## Контекст

Карты в продукте нет: карточка гонки показывает коридор строкой «±N м от маршрута». Стек закладывал MapLibre
(RN + GL JS) и «PMTiles в S3 или MapTiler» (`docs/proposal-stack-architecture.md`); эпик результатов вынес карту и
тайлы за свои рамки как внешний сервис (`docs/tasks/2026-10-27-race-results/epic.md` §7). Приложение — универсальное
Expo SDK 58 (RN 0.88, новая архитектура): iOS, Android, web с SSR. Данные есть: линия показа маршрута (≤ 1000 точек),
старт и финиш (`routes`), `races.corridor` (`routeId`, `widthM`).

Требования: тайлы OSM без собственной инфраструктуры на старте; лицензия, допускающая коммерческое использование;
публичный ключ (если есть) — в бандле (`pokatim-app.md`); смена провайдера — без правки кода; светлая и тёмная тема.

Проверено 2026-10-26 (официальные страницы, context7 недоступен):

| | OpenFreeMap | MapTiler Cloud | Свои PMTiles |
|---|---|---|---|
| Аккаунт, ключ | нет | аккаунт, ключ в URL | хранилище + CDN |
| Стоимость | 0 (донаты) | Free: 5 000 сессий карты/мес, «non-commercial»; Flex — $30/мес + $2,50 за 1 000 сессий | S3/CDN-трафик |
| Лимиты | без лимита просмотров; без SLA | Free — пауза до конца месяца при превышении | свои |
| Коммерция | разрешена | Free — под вопросом, Flex — да | да |
| Стили | Liberty, Bright, Positron, Dark, Fiord | много, свои | сборка своими силами |
| Атрибуция | «OpenFreeMap © OpenMapTiles Data from OpenStreetMap» (MapLibre ставит сама) | логотип MapTiler на Free + © OSM | © OSM, OpenMapTiles |

## Решение

1. **Тайлы — по URL стиля MapLibre из env**, без кода провайдера: `EXPO_PUBLIC_MAP_STYLE_LIGHT` и
   `EXPO_PUBLIC_MAP_STYLE_DARK` (публичные, вшиваются в бандл; ключ провайдера — частью URL, например `?key=`). Не
   заданы — карты нет, карточка показывает текстовую альтернативу (сборка не падает). Смена провайдера — смена env и
   пересборка.
2. **Провайдер на старте — OpenFreeMap** (`https://tiles.openfreemap.org/styles/positron` / `…/dark`): без ключа,
   аккаунта и денег, коммерция разрешена. Риск «нет SLA» закрывает п. 1: переход на MapTiler (Flex) или свои PMTiles —
   сменой URL. Пересмотреть до публичного запуска в сторах.
3. **Атрибуция** — штатный контрол MapLibre (компактный, `customAttribution` не убираем), на native — кнопка
   атрибуции карты. Данные OSM (ODbL) не храним и не перераспространяем — только показ.
4. **Библиотеки:** native — `@maplibre/maplibre-react-native` 11.x (только новая архитектура, RN ≥ 0.80, peer
   `expo ≥ 54`, config plugin `@maplibre/maplibre-react-native` в `app.json`; Expo Go не поддерживается — нужна
   dev-сборка `eas build --profile development`). Web — `maplibre-gl` 6.x в платформенном файле `*.web.tsx`.
5. **SSR:** карта — только клиент. SSR и первый рендер отдают место карты фиксированной высоты (без сдвига вёрстки) и
   текстовую альтернативу; `maplibre-gl` грузится динамическим `import()` после монтирования — на сервере не
   исполняется (код в серверном бандле Metro есть: сервер не делится на чанки), в первый клиентский чанк не попадает
   (отдельный async-чанк). Воркер `maplibre-gl` — свой файл на origin (`setWorkerUrl`, `import.meta.url` в Metro нет).
   Native — пакет MapLibre RN грузится лениво и только при наличии нативного модуля (Expo Go и старый dev-клиент —
   без карты).
6. **Коридор** рисуется линией маршрута шириной 2 × `widthM` в метрах, переведённой в пиксели выражением зума
   (`interpolate exponential 2` по метрам на пиксель на широте маршрута) — без буфер-полигона на сервере; поверх —
   осевая линия, старт и финиш кругами. Цвета — роли темы `map.*` дизайн-системы.
7. **Данные:** публичное чтение `GET /v1/races/:id/route` — линия показа, старт, финиш, рамка, `widthM`; только
   опубликованная/отменённая гонка с коридором и готовым маршрутом, кэш `public, max-age=60`, лимит `public-read`.
8. Панель «Протокол» остаётся с SVG-превью линии (`LinePreview`): карта в панели потребует правки CSP
   (`connect-src`, `worker-src blob:`) — отдельным решением.

## Альтернативы

- **MapTiler сейчас:** нужен аккаунт и ключ пользователя; Free — некоммерческий и с паузой при превышении, Flex —
  $30/мес до запуска. Остаётся сменой URL (п. 1).
- **Свои PMTiles в S3:** S3 и CDN в проекте ещё нет; сборка тайлов Беларуси и их обновление — инфраструктура раньше
  продукта. Пересмотреть при росте трафика или требовании SLA.
- **Растровые тайлы openstreetmap.org:** политика OSMF запрещает нагрузку приложений; нет тёмной темы.
- **`react-map-gl` на web:** лишняя обёртка поверх `maplibre-gl` для одного экрана.
- **Буфер-полигон коридора с сервера:** точнее на изломах, но новая геометрия и вес ответа; визуально ширина линии в
  метрах достаточна (сверка всё равно идёт на сервере по `matchCorridor`).

## Последствия

- Native-сборки требуют пересборки dev-клиента; Expo Go с картой не работает. Jest — мок нативного модуля.
- Без SLA OpenFreeMap: при недоступности тайлов карточка показывает ошибку карты и текстовую альтернативу, сверка
  результатов от тайлов не зависит.
- Вес web: `maplibre-gl` (~1,1 МБ min) — отдельный async-чанк, грузится только на карточке гонки, но хешированный
  чанк попадает в precache service worker — PWA скачивает его при установке всем (follow-up при жалобах на трафик).
  CSS `maplibre-gl` (~70 КБ) Metro web подключает глобально — `<link>` на всех страницах.
- Ошибка стиля или тайлов — сообщение поверх карты без повтора (повтор — перезаход на карточку).
- Следующие слайсы (свой трек с подсветкой вне коридора, «рядом» для райдов, карта в панели) используют тот же
  компонент и env.

## Дополнение 2026-10-27 (routes-04b): интерактивная карта

Решения пользователя I1–I4 (`docs/tasks/2026-10-27-routes-04b-map-interactive/`). Правило статичной карты maps-01
(жесты выключены, камера только по рамке) заменяется — карта гонки, маршрута каталога и «Моего маршрута» (общий
`RouteMap`) двигается и масштабируется, прокрутка страницы не ломается.

1. **Web — кооперативные жесты `maplibre-gl`** (`interactive: true`, `cooperativeGestures: true`): мышь тащит карту,
   колесо с Ctrl/⌘ — зум, без модификатора — прокрутка страницы и подсказка поверх карты; на тач-экране один палец
   прокручивает страницу (`touch-action: pan-x pan-y`), два — двигают и масштабируют карту; двойной клик/тап —
   приближение. Строки подсказки и подпись холста — опция `locale` из `@pokatim/i18n`. Подсказка — штатный слой
   MapLibre (затемнение, нейтрально в обеих темах), при reduce motion — без затухания.
2. **Native — нативные жесты MapLibre остаются выключены**, жесты двумя пальцами (пан, щипок) и двойной тап — RNGH
   поверх карты, камера — императивно (`CameraRef.jumpTo` на кадр, без ре-рендера). Пропсы `dragPan`/`touchZoom`
   MapLibre RN 11 — только вкл/выкл: включённые, они отдают карте и один палец (Android `dragPan` зовёт
   `requestDisallowInterceptTouchEvent`), прокрутка карточки ломается. На время жеста карты экран не прокручивается
   (`MapGestureLockContext`: активация пана или щипка — выкл, конец последнего — вкл). Новых нативных зависимостей нет.
3. **Зум 4–17** (`MAP_MIN_ZOOM`/`MAP_MAX_ZOOM`), без `maxBounds` (свои маршруты бывают за границей); вращение и наклон
   выключены.
4. **Кнопки «+», «−», «в рамку»** — колонка сверху справа (атрибуция «i» — снизу справа); «в рамку» видна всегда.
   Отступ рамки справа — под кнопки. Анимация камеры кнопок и двойного тапа — 300 мс, при reduce motion — без
   анимации (native `fitBounds` по умолчанию — 2 с `'fly'`: длительность передаётся явно). Компонент — локальный
   `MapControls` (`IconButton` в `@rkarakulov/ui` нет — follow-up в app-foundation, как и токен длительности анимации).
5. **Маркер скраббинга** (routes-04) пересчитывает пиксели линии на каждое движение камеры (web — `move`, native —
   события региона) в стор вида карты; на кадр перерисовывается только слой маркера.
6. **Доступность — исключение для сдвига карты:** правило «`accessibilityActions` вместо единственного drag-жеста» для
   сдвига карты на native не выполняется — карта не единственный носитель информации (подпись-альтернатива,
   `adjustable` профиля), масштаб и возврат — кнопками; на web холст в фокусе двигается стрелками, масштаб — «+»/«−».
   Действия «сдвинуть на север…» скринридеру — шум, кнопки-стрелки на карте 220 px — перегруз.

Альтернативы: web — свой обработчик колеса и своя подсказка (дубль библиотеки), `interactive` без кооперативного
режима (колесо и палец «съедают» прокрутку страницы); native — нативные `dragPan`/`touchZoom` (один палец двигает
карту), только нативный щипок без перетаскивания (урезание I1); блокировка прокрутки — RNGH `ScrollView` с отношением
`block` (замена `ScrollView` и `RefreshControl` на трёх экранах) или проп у `RouteMap` (проброс через три обёртки).
Риски: жесты двумя пальцами внутри `ScrollView` на устройстве и кооперативные жесты в мобильном браузере проверяются
вручную (в CI карты нет: стиля в смоуке нет).
