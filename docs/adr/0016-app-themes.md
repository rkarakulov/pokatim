# 0016. Темы приложения: реестр в `@pokatim/design-tokens`, провайдер поверх базы, доставка — публичный GET, кэш native и SSR через `+middleware.ts`

- Статус: Accepted
- Дата: 2026-10-27
- Задача: `docs/tasks/2026-10-27-app-themes` (слайсы B, D1)

## Контекст

Владелец платформы выбирает облик приложения райдера в «Протоколе» (T1: тема глобальная, личной нет). Тема применяется
при запуске и при возврате в приложение без перезапуска и без потери экрана (T2). У части тем пара светлая/тёмная по
системе, у части — всегда тёмная (T3). Тема — токены (цвета, шрифты, форма, плотность, иконки, карта, профиль) и
варианты раскладки (T4). Форма базовых компонентов — токены базы app-foundation (T5, `@rkarakulov/*` 0.5.0). Админка
остаётся в теме `panel` (T6).

## Решение

1. **Реестр — `@pokatim/design-tokens` (`app-themes.ts`):** `appThemes: Record<AppThemeId, AppThemeDefinition>` —
   `colorScheme` (`system` | `dark`), `schemes: { light, dark }` (`AppTheme` = роли базы + группы pokatim `map`,
   `surfaceBar`, `profile` + `shape`), `fonts` (гарнитуры ролей + CSS-стек), `density`, `icons { weight, filled }`,
   `layout`. «Классика» — нынешние `themes.light/dark` (те же объекты). Подложка карты — `map.basemap` (не цвет: в CSS
   панели не выводится), форма — в каждой схеме (`shapeOf(useTheme())` базы), не отдельным полем. Источник id —
   `APP_THEME_IDS` контрактов; токены объявляют тот же состав (палитра не знает о транспорте), равенство — тест
   `apps/app/src/theme/app-theme-ids.test.ts`. Контраст WCAG — для всех тем × схем (`contrastPairsOf`).
2. **Провайдер — `AppThemeProvider` поверх `ThemeProvider` базы:** схема = `appThemeScheme(def, useColorScheme())`
   (системная схема — из базы: на web серверный снимок светлый, гидрация без расхождения). Новая тема применяется после
   загрузки её шрифтов, до того рисуется прежняя; дерево не пересоздаётся — состояние экранов сохраняется. Проектный
   хук — `useAppTheme()` (без провайдера — «Классика»).
3. **Шрифты — `themeFonts(def)` + свой `useThemeFonts`:** `useFonts` expo-font читает карту один раз и смену темы не
   перезагрузил бы. Native бандлит файлы всех гарнитур, грузит набор активной темы (`loadAsync`); web-сервер вызывает
   `loadAsync` синхронно в рендере — в HTML (`#expo-generated-fonts`, preload) только шрифты активной темы; клиент при
   гидрации видит их как загруженные.
4. **Доставка:** публичный `GET /v1/appearance` (`useAppearanceQuery`; перезапрос — фокус/AppState по умолчаниям
   клиента). Native: кэш `pokatim.appTheme` (SecureStore) — тема до ответа сервера; сплэш держится до чтения кэша,
   шрифтов темы и сессии. Незнакомый id (`'unknown'`), битый кэш, нет сети — «Классика» / последняя известная.
5. **SSR — `src/app/+middleware.ts` в серверном бандле, тема — в `globalThis[Symbol.for('pokatim.appTheme')]`.**
   Middleware Expo Router (только GET страниц: не `/_expo/*` и не файлы с расширением) обновляет тему процесса через
   `fetchPublicForSsr` мимо его кэша (`cache: false` — окно одно): один запрос в полёте на процесс, не чаще раза в 60 с
   от завершения прошлой попытки при любом исходе; ждёт только первая страница процесса (таймаут 2 с, затем «Классика»), дальше — обновление в фоне, рендер
   в последней известной теме. `+html.tsx` (фон документа,
   autofill, `theme-color`, `window.__POKATIM_THEME__` — только id из закрытого списка), корень (`initialThemeId`) и
   manifest читают её через `ssrThemeId()`. Почему не Express: у `createRequestHandler` нет per-request контекста
   рендера, а образ `web` не содержит `zod`/контрактов — fetch, таймаут, кэш и список id пришлось бы дублировать в
   `server/`. Тема глобальна: одна на процесс; гонка при смене — максимум одна страница в прежней теме, клиент догонит
   запросом; несколько процессов сходятся за ≤ 60 с.
6. **Иконки — `components/icon.tsx`, единственный вход `expo-symbols`:** реестр имён (SF Symbol + заливочный вариант,
   Material Symbol), заливка и вес — из темы. Ограничения: заливка — только iOS (статичные Material Symbols её не
   умеют); вес на Android/web — отдельный файл шрифта на вес (`expo-symbols/androidWeights/<вес>`, импорт только
   используемых весов), `SymbolView` перемонтируется по весу (шрифт он грузит один раз).

## Последствия

- Компоненты читают только роли темы: `theme.map.basemap` вместо сравнения с `themes.dark`, `theme.profile.*` для
  профиля высоты; сторож — `src/__tests__/theme-guards.test.ts`.
- Слайс C добавляет палитры, гарнитуры, форму и варианты раскладки шести тем без правки экранов; `chart` и превью
  панели на реестре — там же.
- Native-сплэш и системные пикеры следуют системе и цветам «Классики» (вне B).
