# Кофе-райды (блок 05)

Источник: `docs/tasks/2026-10-27-app-05-rides/task.md` (PR 05a), ADR-0013 (Proposed). Жалобы и модерация — PR 05b,
до прода и сторов обязателен.

## Сущность

Кофе-райд — покатушка, которую собирает райдер: название, дата и время старта (Минск), город из справочника и место
встречи текстом, дистанция, темп «от–до», необязательный лимит участников, описание, необязательная подпись
организатора «Как вас подписать». Третья сущность расписания (ADR-0010 п. 1): без окна, протокола, сезона и
результата; повторяющихся райдов нет.

## Жизненный цикл

- Статус: опубликован → отменён (организатором, с причиной). Удаления нет.
- Фаза — по времени сервера, не хранится: `cancelled` (статус) → `past` (с момента старта) → `upcoming`.
- Запись, «Не иду», правка и отмена — только до старта.
- Перенос времени, города или места при других участниках — строка «Время или место старта изменены …» на карточке.

## Участие

- Организатор — первый участник («идёт 1 из 12 · вы»), «Не иду» ему недоступно.
- «Я иду» / «Не иду» — повтор безвреден; мест нет — «Мест нет», листа ожидания нет; снятая отметка освобождает место.
- Лимит 2–100 вместе с организатором; без лимита — технический потолок 100, подпись «идут N».
- Правка лимита — не ниже числа идущих.

## Видимость

- Вкладка «Райды» и раздел Главной — только вошедшим: будущие райды по времени старта, фильтр «Город»; отменённые
  будущие — только участникам и организатору. Прошедших в ленте нет.
- Карточка `/rides/<id>` — по ссылке без входа (web — HTML с сервера), всегда `noindex`; OG — название, дата, город,
  дистанция, темп (без описания и подписи организатора).
- Место встречи видно всем (решение автора); в форме — подсказка «людное место, не домашний адрес».
- Гость нажимает «Я иду» → «Вход» → после входа (в течение 30 минут) снова карточка; записывается повторным нажатием.

## Справочники (только в конец)

- Города (`CITY_CODES`, 25): Минск, Брест, Витебск, Гомель, Гродно, Могилёв, Барановичи, Бобруйск, Борисов, Пинск,
  Орша, Мозырь, Солигорск, Новополоцк, Лида, Молодечно, Полоцк, Жлобин, Светлогорск, Речица, Слуцк, Жодино, Кобрин,
  Слоним, Волковыск.
- Причины отмены: плохая погода, организатор не может, мало участников, состояние дороги, другое.

## Ограничения [ASSUMPTION, Q8]

Название 3–80, подпись организатора 2–80, место 3–120, описание ≤ 1000, дистанция 5–300 км, темп 10–45 км/ч, старт не раньше чем
через 30 минут и не дальше 60 дней; не больше 5 будущих своих райдов и 20 будущих отметок; лимиты частоты —
создание 10/сут, правка и отмена 30/ч, «Я иду»/«Не иду» 60/ч.

## Скрыто и до каких блоков

| Что | Когда |
|---|---|
| «Рядом», «в N км от вас», карта и точка старта | блок «Карта и рядом» (ADR про тайлы/геокодер) |
| Маршрут райда, «Набор», дистанция из маршрута | блок «Маршруты» |
| Фото организатора, карточка-приглашение, шит «Райд опубликован» | модули `sharing` и `media` |
| Имена и аватары участников | профиль райдера |
| Уведомления об отмене и переносе | модуль `notifications` |
| Жалобы, скрытие командой | PR 05b |
| Удаление райда, исключение участника, комментарии, «Мои райды» | не планируется в v1 |

## Ответы автора (2026-10-27)

Место встречи видно всем; имя организатора — необязательное поле «Как вас подписать» (пусто → «Организатор»);
«рядом» и карта — отдельный блок; остальное — по рекомендациям: справочник ~25 городов, лимит необязательный без
листа ожидания, 05b обязателен до прода, отмена — причина из справочника.
