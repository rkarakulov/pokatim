# Гостевой лендинг «Покатим»

Первый экран невошедшего гостя (guest-landing, решения автора G1–G6 от 2026-10-29; задача —
`docs/tasks/2026-10-29-guest-landing/task.md`). Закрывает вопрос Q5 Главной (`home.md`): гостевой ленты нет, гость
видит лендинг.

## Адрес и переходы (G1, G2)

- `/welcome` — один экран на iOS, Android и web. Новый гость без сессии с `/` и с любого экрана под гардом вкладок
  попадает на `/welcome` (раньше — «Регистрация»). Вошедший на `/welcome` уходит на `/`.
- Гость, который на этом устройстве уже входил (`returning`), по-прежнему уходит на «Вход». Живая регистрация после
  перезапуска (токен регистрации не истёк) — по-прежнему «Регистрация» → «Подтвердите e-mail».
- «Зарегистрироваться» и «Войти» — в герое и внизу экрана; «назад» с «Регистрации» возвращает на лендинг.
- Размещение (RC-1): корневой экран рядом с группой «Регистрации» под тем же гардом «без сессии», а не внутри группы:
  под лендингом не лежит форма регистрации, а под «Регистрацией» / «Входом» — лендинг с его запросами.
- Удаление аккаунта по-прежнему ведёт на «Регистрацию» с сообщением «Аккаунт удалён»; возврат после входа не меняется.

## Структура (G3)

1. Герой: знак «Покатим», заголовок, лид, «Зарегистрироваться» и «Войти».
2. «Гонки по маршруту» — текст и ближайшая гонка → карточка гонки.
3. «Сезон» — текст и текущий сезон (название, даты, фаза) → экран сезона; между сезонами — только текст.
4. «Кофе-райды» — только текст: лента райдов — под входом, карточки райдов — UGC с `noindex`.
5. «Маршруты» — текст и до трёх последних **маршрутов команды** → карточка маршрута.
6. «Календарь стартов» — текст и ближайший старт → карточка старта.
7. Нижний призыв «Поехали?» и те же две кнопки.

## Данные (G4)

Только существующие публичные списки: ближайшая гонка, текущий сезон, маршруты, ближайший старт. Новых эндпоинтов нет.

- **Маршруты — только команды** (отступление от G4 `?limit=3`, RC-5): `GET /v1/routes?author=team&limit=3`. Текст
  раздела говорит о маршрутах команды, а маршруты райдеров — UGC с `noindex`; индексируемый лендинг не выносит их в
  выдачу.

## Пусто и ошибки (G5)

- Пусто — текст раздела и подпись без действия: «Пока нет открытых гонок», «Маршрутов пока нет», «Пока нет стартов в
  календаре»; сезона нет — без строки.
- **Отступление от `AGENTS.md` §4.12 (RC-4):** ошибка или нет сети — текст раздела остаётся, живой блок скрыт, без
  «Не удалось загрузить» и «Повторить». Лендинг читается и без API. Первая загрузка — скелетон в слоте; без сети и без
  данных — блока нет (без вечного скелетона); ошибка обновления при показанных данных — данные остаются.

## Web и SEO (G6)

- `/welcome` — HTML с сервера: тексты разделов и кнопки до JS; живые данные — посев `loader` (что успел за таймаут
  SSR-чтения), дальше браузер догружает сам.
- Мета: `<title>` «Покатим — гонки, сезон, кофе-райды и маршруты» (без повтора бренда), description — слоган
  приложения, OG с `og:url` = `/welcome`, без `robots`.
- Мета корня `/` — та же мета лендинга (RC-3): превью ссылки на сайт одно, `og:url` — `/welcome`; тело `/` не
  меняется.
- «Сегодня / завтра» и «До старта N дней» — только после монтирования; на сервере и при гидрации — даты с годом.
- OG-картинка `/welcome` и `/` — бренд-карточка «Покатим» (og-images, шаблон «Классика»).
- `robots.txt` (landing-seo): открыты публичные страницы; закрыты экраны только для вошедших, онбординг, ссылки с
  токеном, билеты, `/admin/`. `/v1/` открыт: Googlebot при рендере соблюдает robots и для fetch, а публичные экраны
  догружают данные из API (таблица сезона) и картинки превью. Профили райдеров и кофе-райды не закрыты — у них
  `noindex` в мета. `Sitemap` — от `WEB_ORIGIN`.
- `sitemap.xml` (landing-seo, sitemap-index) — sitemap index: дочерние карты в корне сайта (протокол: карта перечисляет
  только URL ниже своего каталога) — `/sitemap.xml?kind=static` (`/welcome`) и `/sitemap.xml?kind=<вид>&page=<n>` по
  10 000 объектов — **все** опубликованные гонки, сезоны, маршруты каталога и старты
  календаря, страницы по `_id` (правка объекта не переносит его, новые — в конец; `GET /v1/sitemap` и
  `/v1/sitemap/:kind/:page`, мемо API 10 мин). `lastmod` — дата изменения; у страницы — последнее изменение её
  объектов, а если её состав сменился (публикация старого черновика, снятие, сдвиг границ) — момент сборки индекса; у
  сезона — нет. Профилей райдеров и кофе-райдов нет (`noindex`). API недоступен — `503` + `Retry-After`.
