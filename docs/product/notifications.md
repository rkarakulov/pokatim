# Уведомления: центр, push, письма

Решения автора (human gate 2026-10-27). Задача: `docs/tasks/2026-10-27-notifications/task.md`, ADR-0017. Экран 13
прототипа «Центр уведомлений». Решение A11 эпика результатов: уведомления — отдельный модуль `notifications`, модули
только пишут события в outbox.

`[ASSUMPTION]` — автор не отвечал, решение принято по рекомендации, его можно пересмотреть.

## Решения N1–N12

- **N1 — каналы.** Центр уведомлений в приложении (все платформы) и push на iOS и Android через Expo Push. Web push
  — позже: в web уведомления видны в центре и на колокольчике. Запрет push в MVP (AGENTS §1) снят ADR-0017.
  **Обновлено (ADR-0022):** в PWA — Web Push тем же каналом (Android Chrome, desktop Chrome/Edge, iOS 16.4+ — только
  установленная PWA); где не поддерживается — опции нет.
- **N2 — e-mail только для трёх событий:** «Решение по спору», «Райд отменён» и напоминание о событии с билетом
  (event-tickets PR D, кнопка «Открыть билет»). Остальное — центр и push. Письма об
  аккаунте (подтверждение, сброс, удаление) не меняются.
- **N3 — события v1** (тексты — ниже):

  | Группа | Событие | Кому |
  |---|---|---|
  | Гонки и результаты | Результат засчитан | райдеру попытки |
  | | Результат не засчитан | райдеру попытки |
  | | Протокол опубликован | участникам гонки |
  | | Протокол пересчитан (дисквалификация, её отмена, перепроверка) | участнику (дисквалификация) или всем участникам (перепроверка) |
  | Споры | На ваш результат подан спор | райдеру, на чей результат спор |
  | | Спор отозван | райдеру, на чей результат спор |
  | | Райдер ответил на ваш спор | автору спора (без текста ответа, D-51) |
  | | Решение по спору | автору спора и райдеру, на чей результат спор |
  | Райды | Райд отменён | участникам «Иду» |
  | | Райд перенесён (время или место старта) | участникам «Иду» |
  | | Новый участник | организатору |
  | | Жалоба рассмотрена | автору жалобы |

  | Мероприятия | Напоминание о событии (правило организатора «за N ч», event-tickets PR D) | участникам с активным билетом, выпущенным до времени отправки |
  | | Имя / фото / клуб в профиле сброшены модератором (profile-moderation-followups) | самому райдеру |
  | Достижения | Новое достижение, новый уровень, сезонное (achievements-push P1) | самому райдеру |
  | Свои | «Свои идут», «Спасибо за компанию», «Вас добавили в свои», «Респект», «По вашей ссылке зарегистрировались», «Как прошёл райд?» (`social.md` K10) | по таблице K10 |

  «Аккаунт удалён» в центр не пишется: читать его некому, остаётся письмо (A10 `account.md`).
  Достижение, найденное, пока райдер в приложении (сверка при открытии достижений, вспышка), — только запись в центре,
  без push; найденное серверной сверкой — центр и push (achievements-push P1). Тихие выдачи (первая сверка,
  восстановление, понижение) — без уведомления. На одну выдачу и уровень — одно уведомление; новый уровень заменяет
  прежнее и снова непрочитан (N7).
  Ручная выдача командой (achievements-panel) — то же уведомление, что у серверной сверки (центр и push, текст и
  название объекта — как у обычной выдачи); ручной отзыв и «Вернуть автоматике» — без уведомления. Повторная ручная
  выдача того же уровня на прежней выдаче в течение 90 дней второго push не даёт (схлопывание по выдаче и уровню,
  RC-3) — вспышка в приложении есть. Отозвана до доставки — уведомления нет.
- **N4 — настройки по группам.** Семь групп: «Гонки и результаты», «Споры», «Райды», «Маршруты», «Мероприятия»
  (PR D), «Достижения» (achievements-push P4: только push, подресурс `settings/achievements`, по умолчанию включена
  без наследования от других групп) и «Свои» (`social.md` K10: последней, только push, подресурс `settings/social`;
  старые сборки её не видят). В каждой — тумблер push. У групп «Споры», «Райды» и «Мероприятия» — ещё тумблер e-mail (только события
  N2); у «Маршрутов» писем нет — только push. Тумблеры «Мероприятий» и «Маршрутов» — отдельные подресурсы
  `settings/events` и `settings/routes` (старые сборки видят прежние три группы). В центре уведомления видны всегда.
  По умолчанию всё включено; «Маршруты», которые райдер ещё не переключал, следуют тумблеру push «Райдов» (раньше
  решения по маршруту были в «Райдах»: выключивший их не начнёт получать push). Решение координатора (2026-10-28):
  решение по заявке маршрута — отдельная группа «Маршруты» (на экране — после «Райдов»); уже созданные уведомления
  остаются в своей группе (снимок).
  `[ASSUMPTION]` Сброс имени, фото или клуба модератором — в группе «Райды» (2026-10-30).
- **N5 — разрешение push.** Приложение не спрашивает разрешение при запуске и при открытии экранов. В центре и в
  настройках — строка «Включить push-уведомления»; нажатие вызывает системный запрос. Отказ — строка ведёт в
  системные настройки (web — объясняет, где включить в браузере). Решение 2026-10-30: в момент пользы — сразу после
  успешного «Я иду» на райде и после записи на гонку — своя подсказка под действием («Включить» / «Не сейчас»).
  Системный запрос — только по «Включить» (жест пользователя); выдано — подсказка исчезает, отказ — текст отказа,
  без повторного запроса. «Не сейчас» — 30 дней не показываем на этом устройстве (запрос не тратится). Подсказки нет,
  если push не поддержан, разрешение уже выдано или отказано навсегда; за запуск приложения — не больше одного показа.
- **N6 — тихие часы, настраиваемые.** Начало и конец выбирает райдер (по часам, Europe/Minsk). По умолчанию
  включены, 22:00–08:00. В тихие часы push откладывается до конца интервала, в центре уведомление появляется сразу.
  `[ASSUMPTION]` Письма тихие часы не задерживают.
- **N7 — группировка.** `[ASSUMPTION]` Несколько отложенных push уходят одним: «У вас N новых уведомлений». Повтор по
  тому же объекту (перенос райда дважды, «Новый участник» в одном райде) заменяет прежнее уведомление в центре и
  становится непрочитанным снова. `[ASSUMPTION]` Не больше 20 push в час на райдера; сверх — только центр.
- **N8 — хранение 90 дней.** Старше — удаляются автоматически.
- **N9 — прочтение по нажатию.** Нажатие на уведомление отмечает его прочитанным; есть «Прочитать все». Открытие
  центра счётчик не сбрасывает. Счётчик на колокольчике — до «99+». Обновление — polling.
- **N10 — deep link на экран объекта.** Гонка — карточка гонки, спор — карточка гонки (статус спора там же),
  «На ваш результат подан спор» — экран ответа на спор, райд — карточка райда,
  решение по заявке маршрута — карточка своего маршрута (`/routes/mine/<id>`), сброс поля профиля — «Редактировать
  профиль» (`/settings/profile`, цель `profile-edit` без id), новое достижение — экран достижения
  (`/achievements/<код>`, сезонное — `?season=<id>`; цель `achievement` с кодом из каталога). Сервер хранит тип цели и id;
  приложение строит путь только из списка известных целей, адресов из push не принимает. Объект удалён —
  обычное «Не найдено» экрана.
- **N11 — удаление аккаунта.** В транзакции удаления снимаются все push-токены: push перестают уходить сразу.
  Фоновая очистка стирает уведомления, настройки и отложенные push. Сами события в чужих уведомлениях не
  меняются: имени удалённого райдера в текстах нет (N12).
- **N12 — тексты без чужих ПДн.** В уведомлении — название гонки или райда, дата, место. Имён других райдеров,
  текстов споров, ответов и заметок модератора нет. Исключение — группа «Свои» (`social.md` K10): уведомление
  хранит id действующих лиц, публичное имя подставляется при чтении (нет публичного профиля или аккаунт удалён —
  «Райдер»); в тексте push имя остаётся на устройстве (принятый риск).
- **Выход из аккаунта** снимает push-токен этого устройства: следующий владелец устройства чужих push не получит.
- **Старые события.** `[ASSUMPTION]` Событие старше 72 часов к моменту обработки уведомления не создаёт (в том
  числе накопленные до выката события споров и протоколов).
- **Старые сборки (achievements-push P6, RC-P8).** Новую группу, вид и цель старая сборка не знает: строка
  уведомления показывается (текст — снимок сервера), группа и вид — «неизвестно», нажатие — без перехода; push такой
  цели открывает центр. Центр и настройки не ломаются.

## Где в продукте

- Главная: колокольчик в верхней панели со счётчиком непрочитанных → экран «Уведомления» (`/notifications`).
- «Уведомления»: список (новые сверху), непрочитанные выделены, «Прочитать все», строка включения push,
  вход в настройки.
- «Настройки уведомлений» (`/settings/notifications`): группы × push/e-mail (включая «Мероприятия» и «Достижения»),
  тихие часы. Вход — из центра и из
  профиля.

## Риски и ограничения

- **EAS и ключи push.** Для push-токена нужен EAS `projectId`, для доставки — ключ APNs и FCM в EAS. Пока их нет,
  приложение не регистрирует токен, центр и колокольчик работают. Ручной шаг — `docs/runbooks/push.md`.
- **Рейтинг сезона (слайс 08)** событий протокола не слушает: outbox ведёт тип в одну очередь, поэтому 08 обошёлся
  регламентом сверки (раз в минуту, DV-1). Fan-out outbox (ADR-0017) и подписка рейтинга на события — follow-up.
- **Web push** — отдельным слайсом.
