# Главная (приложение, блок 02)

Решения автора и рекомендации архитектора от 2026-10-26 (`docs/tasks/2026-10-26-app-02-home/task.md`, Q1–Q9).

## Состав v1

- Верхняя панель — словесный знак «Покатим», колокольчик уведомлений со счётчиком непрочитанных (до «99+», опрос раз в
  минуту) → «Уведомления» (`docs/product/notifications.md`), «Устройства», «Настройки» и квадратный аватар последним
  справа → свой профиль `/profile` (rider-profile; фото нет — иконка человека).
- Лента разделов в одном ритме: шапка (кикер раздела, заголовок), один типографский герой, мета, «Все …» → вкладка.
  - **«Гонки»** — «Ближайшие гонки»: ближайшая опубликованная гонка с незакрытым окном. Даты окна по Минску крупно,
    название, «{км} км · {покрытия}», строка окна по фазе сервера: откроется / открыто до / закрывается сегодня,
    завтра. «Все гонки» → вкладка «Гонки».
  - **«Кофе-райды»** (блок 05) — «Ближайшие кофе-райды»: ближайший будущий райд ленты (под входом, `limit: 1`).
    Дата «Сб 3 октября, 9:00», название, «{км} км · темп {a–b} км/ч · {город}, {место}», стопка «идут N из M» и
    «Я иду» / «Вы идёте» / «Вы организатор» / «Мест нет» по ответу сервера; пусто — «Пока нет кофе-райдов» +
    «Создать райд». «Все райды» → вкладка «Райды».
  - **«Маршруты»** (routes-01, `routes.md`) — «Маршруты команды»: последний опубликованный маршрут каталога,
    текстовый герой — длина крупно («86 км»), название, «набор · петля», «город · покрытие» (линии на Главной нет,
    RC-8 — у темы «Классика»; темы с картой показывают контур маршрута, app-themes, `routes.md`); пусто — «Маршрутов пока нет» (раздел не скрывается, Q9). «Все маршруты» → вкладка «Маршруты».
  - **«Календарь стартов»** — «Ближайшие старты»: ближайший опубликованный старт. Дата (многодневный — диапазон),
    «{дистанции} · {дисциплина} · {город}», «До старта N дней.» / «Старт сегодня.» / «Идёт сейчас.»; при ссылке
    организатора — «Регистрация у организатора.» текстом. «Все старты» → вкладка «Календарь».
- **«Свои»** (`social.md` K7, этап 0) — только при наличии строк, не больше трёх, затем «Все свои»: «Катя Л. и ещё 2
  идут» → райд в ближайшие 7 дней, результат своего в протоколе за 7 дней, новый маршрут своего в каталоге за 7 дней.
  Порядок: первой, если в опросе выбраны «Кофе-райды»; иначе после разделов по опросу. Без публичного имени —
  подсказка «Добавьте имя — свои увидят вас» («Не сейчас» скрывает на 14 дней, K3). P3: подсказка стоит в слоте
  будущей секции — при «Кофе-райдах» в опросе над всеми разделами (под «Вашими билетами»), иначе после выбранных в
  опросе разделов и до остальных; «Не сейчас» хранится на устройстве, не на сервере.
- «Выйти» и витрина (dev) — внизу Главной, пока нет экрана профиля (Q8).

## Правила

- **Порядок (Q4).** Разделы, отмеченные в опросе «Что вас привело?», — первыми с тегом «по вашему выбору», между
  собой — в порядке вкладок. «Пока просто смотрю», раздел без бэкенда, профиль ещё не загружен или не загрузился —
  порядок вкладок без тегов, ошибки на экране нет. Профиль пришёл позже разделов — порядок меняется один раз.
- **Разделы без бэкенда скрыты (Q2):** без заглушек «скоро». «Кофе-райды» — с блока 05 (`docs/product/rides.md`),
  «Маршруты» — с routes-01 (`docs/product/routes.md`); ответы опроса «Кофе-райды» и «Маршруты» поднимают свой раздел.
- **Без сезона (Q3)** — таблица и место в сезоне на вкладке «Гонки».
- **Только для вошедших (Q5).** Гость без сессии видит не Главную, а гостевой лендинг `/welcome` (guest-landing,
  `docs/product/landing.md`); гостевой ленты и вкладок без входа нет.
- **Герой гонки ведёт в карточку гонки** (Q12 блока 03), **герой старта — в карточку старта** `/calendar/<id>`
  (блок 04); «Регистрация у организатора.» на герое — текстом, кнопка регистрации — на карточке. «Участвовать» —
  с участием.
- **Пусто (Q9):** пустой герой раздела («Пока нет открытых гонок» + «Календарь стартов»; «Пока нет стартов в
  календаре»), без общего пустого экрана.
- **Новое значение справочника у старой сборки:** фаза — без строки окна, покрытие и дисциплина — без подписи.
- **Обновление:** pull-to-refresh (iOS, Android), возврат приложения из фона и фокус вкладки браузера; данные
  публичного API кешируются до минуты.
