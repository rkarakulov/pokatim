# Гонки, сезоны и календарь стартов

Решения автора 2026-10-26 (task `docs/tasks/2026-10-26-admin-02-seasons-races`, §8.1–§8.2) и правила, которые проверяет
сервер (ADR-0010). Макеты автора конфиденциальны; здесь — только решения.

## Три сущности

| Сущность | Кто создаёт | Суть |
|---|---|---|
| Гонка по коридору | команда платформы в панели (организатор — свои, admin — все) | окно дат: проехать коридор в любой день окна; плановая дата протокола; сезон — по концу окна |
| Старт календаря | admin в панели | внешний массовый старт с регистрацией у организатора; без окна, протокола и сезона |
| Кофе-райд | райдер в приложении | время и место старта, лимит, «Я иду» — отдельный модуль `rides` (не в этом слайсе) |

## Сезон

- Название обязательно («Сезон 2026»), даты — календарные Минска, конец включительно.
- Статуса публикации нет: «Предстоящий» / «Текущий» / «Завершён» — по датам.
- Сезоны не пересекаются; промежутки между сезонами допустимы, но конец окна опубликованной гонки обязан попасть в
  сезон (D-84).
- Даты завершённого сезона — только для чтения (имя менять можно); сжать сезон так, что его гонки окажутся снаружи,
  нельзя; удаление сезона — нет.
- Создаёт и меняет только admin; модератор и организатор — чтение.

## Гонка

- Жизненный цикл: черновик → опубликована → отменена. Черновик можно удалить; опубликованную — только отменить
  (необратимо, причина — шаблон из пяти, без свободного текста, D-20). Публикация — без согласования (Q6).
- Поля: название, класс (Шоссе, ТТ, Гравий, МТБ), покрытие — мультивыбор (Асфальт, Гравий), дистанция, описание, окно
  (начало и конец с явным временем, конец включает последнюю минуту — «до 23:59»), плановая дата протокола.
- Правила: окно ≤ 60 суток `[ASSUMPTION]`; протокол — не раньше конца окна + 48 ч; опубликовать можно, пока окно не
  прошло и конец окна попадает в сезон.
- Правка опубликованной (V-11): до окна — всё; окно открыто — начало окна зафиксировано; окно закрыто — только описание
  и плановая дата протокола, причём только позже текущей.
- Эталонный коридор (Q4): до слайса «Маршруты» гонка — анонс без коридора, дистанция вводится вручную; слайс маршрутов
  сделает коридор обязательным до участия. Обложки нет (Q9).
- Права: организатор видит и меняет только свои гонки (чужая — «не найдена»), admin — все, модератор — чтение.

## Календарь стартов

- Запись публикуется сразу; «Снять с публикации» — с причиной (в журнал), «Вернуть в календарь».
- Поля: название, дата (многодневный — до 14 дней `[ASSUMPTION]`), время старта, дисциплина (Шоссе, Гравий, МТБ),
  город, место, дистанции (1–5), ссылка на регистрацию — необязательна, только `https` (Q12), описание.
- Приложение по умолчанию показывает старты с сегодняшнего дня по Минску; фильтры — дисциплина, город, месяц.

## Ответы автора (Q1–Q16)

Q2 — организатор: свои гонки, admin — все, сезоны и календарь — admin; Q4 — анонс без коридора; Q11 — календарь в
этом слайсе; остальные — рекомендации архитектора: Q1 три сущности; Q3 организатор видит только свои; Q5 сезон без
статусов; Q6 черновик → опубликована → отменена; Q7 повторяющихся райдов нет; Q8 у гонки нет времени старта, места,
лимита; Q9 обложек нет; Q10 справочники выше; Q12 ссылка необязательна; Q13 модератор — чтение гонок и сезонов; Q14
чтение приложения публичное; Q15 календарь в панели — таблица; Q16 название сезона обязательно.
