# Гонки, сезоны и календарь стартов

Решения автора 2026-10-26 (task `docs/tasks/2026-10-26-admin-02-seasons-races`, §8.1–§8.2) и правила, которые проверяет
сервер (ADR-0010). Макеты автора конфиденциальны; здесь — только решения.

## Три сущности

| Сущность | Кто создаёт | Суть |
|---|---|---|
| Гонка по коридору | команда платформы в панели (организатор — свои, admin — все) | окно дат: проехать коридор в любой день окна; плановая дата протокола; сезон — по концу окна |
| Старт календаря | admin в панели | внешний массовый старт с регистрацией у организатора; без окна, протокола и сезона |
| Кофе-райд | райдер в приложении | время и место старта, лимит, «Я иду» — отдельный модуль `rides` (не в этом слайсе) |

## Сезон

- Название обязательно («Сезон 2026»), даты — календарные Минска, конец включительно.
- Статуса публикации нет: «Предстоящий» / «Текущий» / «Завершён» — по датам.
- Сезоны не пересекаются; промежутки между сезонами допустимы, но конец окна опубликованной гонки обязан попасть в
  сезон (D-84).
- Даты завершённого сезона — только для чтения (имя менять можно); сжать сезон так, что его гонки окажутся снаружи,
  нельзя; удаление сезона — нет.
- Создаёт и меняет только admin; модератор и организатор — чтение.

## Гонка

- Жизненный цикл: черновик → опубликована → отменена. Черновик можно удалить; опубликованную — только отменить
  (необратимо, причина — шаблон из пяти, без свободного текста, D-20). Публикация — без согласования (Q6).
- Поля: название, класс (Шоссе, ТТ, Гравий, МТБ), покрытие — мультивыбор (Асфальт, Гравий), дистанция, описание, окно
  (начало и конец с явным временем, конец включает последнюю минуту — «до 23:59»), плановая дата протокола.
- Правила: окно ≤ 60 суток `[ASSUMPTION]`; протокол — не раньше конца окна + 48 ч; опубликовать можно, пока окно не
  прошло и конец окна попадает в сезон.
- Правка опубликованной (V-11): до окна — всё; окно открыто — начало окна зафиксировано; окно закрыто — только описание
  и плановая дата протокола, причём только позже текущей.
- Эталонный коридор (Q4): до слайса «Маршруты» гонка — анонс без коридора, дистанция вводится вручную; слайс маршрутов
  сделает коридор обязательным до участия. Обложки нет (Q9).
- Права: организатор видит и меняет только свои гонки (чужая — «не найдена»), admin — все, модератор — чтение.

## Календарь стартов

- Запись публикуется сразу; «Снять с публикации» — с причиной (в журнал), «Вернуть в календарь».
- Поля: название, дата (многодневный — до 14 дней `[ASSUMPTION]`), время старта, дисциплина (Шоссе, Гравий, МТБ),
  город, место, дистанции (1–5), ссылка на регистрацию — необязательна, только `https` (Q12), описание.
- Приложение по умолчанию показывает старты с сегодняшнего дня по Минску; фильтры — дисциплина, город, месяц.

## Приложение (блок 03, `docs/tasks/2026-10-26-app-03-races/task.md`)

- **Вкладка «Гонки»** (только для вошедших): заголовок «Гонки» и справа кнопка сезона — текущий, между сезонами —
  ближайший предстоящий, иначе последний завершённый; сезонов нет — кнопки нет (Q3). Фильтры «Класс» (Шоссе · ТТ ·
  Гравий · МТБ) и «Дата» (текущий месяц по Минску и два следующих, Q6): внутри группы — ИЛИ, между — И; при активных
  чипах — «Сбросить фильтры», без счётчика «Найдено N» (Q5); предустановки класса из профиля нет (Q7). Герой
  «Ближайшая гонка» / «Ближайшая по фильтрам» — первая открытая или предстоящая гонка, ведёт в карточку. «Все гонки»:
  «Скоро» (остальные открытые и предстоящие) и «Завершённые» (закрытые и отменённые, новые сверху) — после того как
  открытые закончились (Q4); подгрузка у конца списка по 20.
- **Строка окна:** «Окно откроется …» / «Окно открыто до …» (сегодня, завтра — отдельно) / «Окно закрыто. Протокол —
  {дата}», после плановой даты протокола — «Окно закрыто. Протокол ожидается» (Q9); отменённая — баннер «Гонка
  отменена. Причина: {причина}.» — тот же текст, что в превью панели (Q13).
- **Карточка гонки** `/races/<id>` (`pokatim://races/<id>`) — публичная ссылка: открывается без входа и без
  установки, поверх вкладок без таб-бара, «Назад» без истории — во вкладку (вошедший) или на главную (гость) (Q8).
  Типографский герой «Гонка · {класс}», окно и время закрытия, дистанция, класс, покрытия, сезон ссылкой, «Протокол
  {дата} (план)», описание — как есть, без разметки и кликабельных ссылок. Даты — всегда с годом. Черновик и
  неизвестная — «Гонка не найдена» + «Все гонки». В web — HTML с сервера и OG (название, даты окна, класс,
  дистанция) без персональных данных, OG-картинки нет (Q14).
- **Экран сезона** `/seasons/<id>` — публичный: название, даты, фаза («Текущий» / «Предстоящий» / «Завершён»),
  гонки сезона (по концу окна), «Другие сезоны». Таблицы сезона, мест и заметки о зачёте нет до модуля рейтинга
  (FR-4, Q1, Q2).
- **Скрыто до своих блоков:** «Участвовать» и участие (V-12), загрузка трека, плашки и блок результатов (блок 04),
  таблица сезона и место (FR-4), коридор и карта (маршруты), обложки, «Поделиться» и OG-картинка (шеринг), лид
  «Проедьте коридор…» (Q10), фильтр «Доступно мне», universal/app links (слайс 5 онбординга).

  При активных чипах — «Сбросить фильтры» без счётчика (Q5). Герой «Ближайший старт» / «Ближайший по фильтрам» — тот

- **Карточка старта** `/calendar/<id>` (`pokatim://calendar/<id>`) — публичная ссылка: без входа и без установки,
  поверх вкладок, «Назад» без истории — во вкладку (вошедший) или на главную (гость); «Войти» гостю не показывается
  (Q10). Типографский герой: кикер «Календарь», «{Дисциплина} · массовый старт · вне приложения», название, дата с
  годом; «Старт в {время} · {город}, {место}»; дистанции — стат-блок «100 км / Дистанция» (Q7); «О старте» — как
  есть. В web — HTML с сервера и OG (дата, дисциплина, город, дистанции) без персональных данных, только текст (Q17).
- **Регистрация у организатора:** кнопка — только при ссылке `https` (повторная проверка `RegistrationUrl`) и пока
  старт не прошёл; открывает сайт организатора в системном браузере (web — новая вкладка без opener и Referer, Q4)
  с пояснением «Откроется сайт организатора. Регистрация и оплата — там.». Фаза — с сервера (`phase`, Q3): после
  последнего дня по Минску — «Старт прошёл.» без кнопки (Q8), идущий — «Идёт сейчас.» над кнопкой.
- **Скрыто до своих блоков:** обложки и галерея (медиа), комментарии и «Войти» гостя (комментарии), «Этот старт в
  других разделах» (маршруты), «Регистрация открыта» (нет статуса регистрации в модели), «Найдено N» (Q5),

## Как засчитывается проезд (эпик «Результат гонки», слайс 02)

Решения автора A2, A4–A7 (`docs/tasks/2026-10-27-race-results/epic.md` §6); проверку делает только сервер.

- **Коридор** — маршрут гонки ± допуск (по умолчанию 50 м, A2). Старт и финиш — концы маршрута, ворота — круг
  радиусом не меньше 30 м.
- **Время** (A4) — от выхода из ворот старта до входа в ворота финиша, **включая остановки**. Моменты пересечения
  ворот считаются между точками трека, результат — в целых секундах (A7: равенство — до секунды).
- **Окно** (A5) — весь путь от старта до финиша внутри окна гонки; запись можно начать раньше окна.
- **Весь маршрут** — проехать все отрезки по 250 м (≥ 98 % и без пропуска длиннее 500 м подряд) в правильном
  направлении; «туда-обратно», петли и несколько кругов в одном заезде поддерживаются (в зачёт — лучший круг).
- **Сход** (A6) — не засчитан, если вне коридора больше 2 % пройденного на отрезке старт → финиш или один выход
  длиннее 500 м; ровно 2 % и ровно 500 м — засчитано.
- **Отказ с причиной:** нет старта, нет финиша, обратное направление, пропуск участка, разрыв записи GPS, сход с
  коридора, вне окна. Одиночные «прыжки» GPS отбрасываются.
