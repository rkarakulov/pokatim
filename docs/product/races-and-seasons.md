# Гонки, сезоны и календарь стартов

Решения автора 2026-10-26 (task `docs/tasks/2026-10-26-admin-02-seasons-races`, §8.1–§8.2) и правила, которые проверяет
сервер (ADR-0010). Макеты автора конфиденциальны; здесь — только решения.

## Три сущности

| Сущность | Кто создаёт | Суть |
|---|---|---|
| Гонка по коридору | команда платформы в панели (организатор — свои, admin — все) | окно дат: проехать коридор в любой день окна; плановая дата протокола; сезон — по концу окна |
| Старт календаря | admin в панели | внешний массовый старт с регистрацией у организатора; без окна, протокола и сезона |
| Кофе-райд | райдер в приложении | время и место старта, лимит, «Я иду» — модуль `rides`, `docs/product/rides.md` |

## Сезон

- Название обязательно («Сезон 2026»), даты — календарные Минска, конец включительно.
- Статуса публикации нет: «Предстоящий» / «Текущий» / «Завершён» — по датам.
- Сезоны не пересекаются; промежутки между сезонами допустимы, но конец окна опубликованной гонки обязан попасть в
  сезон (D-84).
- Даты завершённого сезона — только для чтения (имя менять можно); сжать сезон так, что его гонки окажутся снаружи,
  нельзя; удаление сезона — нет.
- Создаёт и меняет только admin; модератор и организатор — чтение.

## Гонка

- Жизненный цикл: черновик → опубликована → отменена. Черновик можно удалить; опубликованную — только отменить
  (необратимо, причина — шаблон из пяти, без свободного текста, D-20). Публикация — без согласования (Q6).
- Поля: название, класс (Шоссе, ТТ, Гравий, МТБ), покрытие — мультивыбор (Асфальт, Гравий), дистанция, описание, окно
  (начало и конец с явным временем, конец включает последнюю минуту — «до 23:59»), плановая дата протокола.
- Правила: окно ≤ 60 суток `[ASSUMPTION]`; протокол — не раньше конца окна + 48 ч; опубликовать можно, пока окно не
  прошло и конец окна попадает в сезон.
- Правка опубликованной (V-11): до окна — всё; окно открыто — начало окна зафиксировано; окно закрыто — только описание
  и плановая дата протокола, причём только позже текущей.
- Эталонный коридор (race-results-01, ADR-0012 Proposed): маршрут команды платформы из GPX или KML (загрузка в форме гонки
  панели, разбор на сервере; готовый маршрут не меняется) + допуск «±N м от маршрута» — 20–200 м шагом 5, по умолчанию
  50. С коридором дистанция гонки — длина маршрута (0,1 км), вручную не вводится; без коридора — анонс, дистанция
  вручную, публикация как раньше. Коридор задаётся и меняется у черновика и до окна; в открытом окне — только гонке
  без коридора; после закрытия окна — нет. Старт и финиш — концы маршрута. В приложении — строка «Коридор: ±50 м от
  маршрута» и «62 км по GPS-треку» (карты нет). Обложки нет (Q9). Карта коридора на карточке (maps-01/02, свой трек
  участника) с routes-04b интерактивна, как карта маршрута (`docs/product/routes.md`): телефон — одним пальцем
  (routes-04c; вне карты — прокрутка), web — мышью и Ctrl/⌘ + колесо, кнопки «+», «−», «Показать маршрут целиком»; коридор и трек — на любом масштабе.
  Скраббинга на карте гонки нет (follow-up).
- Права: организатор видит и меняет только свои гонки (чужая — «не найдена»), admin — все, модератор — чтение.

## Календарь стартов

- Запись публикуется сразу; «Снять с публикации» — с причиной (в журнал), «Вернуть в календарь».
- Поля: название, дата (многодневный — до 14 дней `[ASSUMPTION]`), время старта, дисциплина (Шоссе, Гравий, МТБ),
  город, место, дистанции (1–5), ссылка на регистрацию — необязательна, только `https` (Q12), описание.
- Приложение по умолчанию показывает старты с сегодняшнего дня по Минску; фильтры — дисциплина, город, месяц.

## Приложение (блок 03, `docs/tasks/2026-10-26-app-03-races/task.md`)

- **Вкладка «Гонки»** (только для вошедших): заголовок «Гонки» и справа кнопка сезона — текущий, между сезонами —
  ближайший предстоящий, иначе последний завершённый; сезонов нет — кнопки нет (Q3). Фильтры «Класс» (Шоссе · ТТ ·
  Гравий · МТБ) и «Дата» (текущий месяц по Минску и два следующих, Q6): внутри группы — ИЛИ, между — И; при активных
  чипах — «Сбросить фильтры», без счётчика «Найдено N» (Q5); предустановки класса из профиля нет (Q7). Герой
  «Ближайшая гонка» / «Ближайшая по фильтрам» — первая открытая или предстоящая гонка, ведёт в карточку. «Все гонки»:
  «Скоро» (остальные открытые и предстоящие) и «Завершённые» (закрытые и отменённые, новые сверху) — после того как
  открытые закончились (Q4); подгрузка у конца списка по 20.
- **Строка окна:** «Окно откроется …» / «Окно открыто до …» (сегодня, завтра — отдельно) / «Окно закрыто. Протокол —
  {дата}», после плановой даты протокола — «Окно закрыто. Протокол ожидается» (Q9); отменённая — баннер «Гонка
  отменена. Причина: {причина}.» — тот же текст, что в превью панели (Q13).
- **Карточка гонки** `/races/<id>` (`pokatim://races/<id>`) — публичная ссылка: открывается без входа и без
  установки, поверх вкладок без таб-бара, «Назад» без истории — во вкладку (вошедший) или на главную (гость) (Q8).
  Типографский герой «Гонка · {класс}», окно и время закрытия, дистанция, класс, покрытия, сезон ссылкой, «Протокол
  {дата} (план)», описание — как есть, без разметки и кликабельных ссылок. Даты — всегда с годом. Черновик и
  неизвестная — «Гонка не найдена» + «Все гонки». В web — HTML с сервера и OG (название, даты окна, класс,
  дистанция) без персональных данных, OG-картинки нет (Q14).
- **Экран сезона** `/seasons/<id>` — публичный: название, даты, фаза («Текущий» / «Предстоящий» / «Завершён»),
  гонки сезона (по концу окна), «Другие сезоны». Таблицы сезона, мест и заметки о зачёте нет до модуля рейтинга
  (FR-4, Q1, Q2).
- **Скрыто до своих блоков:** «Участвовать» и участие (V-12), загрузка трека, плашки и блок результатов (блок 04),
  таблица сезона и место (FR-4), коридор и карта (маршруты), обложки, «Поделиться» и OG-картинка (шеринг), лид
  «Проедьте коридор…» (Q10), фильтр «Доступно мне», universal/app links (слайс 5 онбординга).

## Как засчитывается проезд (эпик «Результат гонки», слайс 02)

Решения автора A2, A4–A7 (`docs/tasks/2026-10-27-race-results/epic.md` §6); проверку делает только сервер.

- **Коридор** — маршрут гонки ± допуск (по умолчанию 50 м, A2). Старт и финиш — концы маршрута, ворота — круг
  радиусом не меньше 30 м.
- **Время** (A4) — от выхода из ворот старта до входа в ворота финиша, **включая остановки**. Моменты пересечения
  ворот считаются между точками трека, результат — в целых секундах (A7: равенство — до секунды).
- **Окно** (A5) — весь путь от старта до финиша внутри окна гонки; запись можно начать раньше окна.
- **Весь маршрут** — проехать все отрезки по 250 м (≥ 98 % и без пропуска длиннее 500 м подряд) в правильном
  направлении; «туда-обратно», петли и несколько кругов в одном заезде поддерживаются (в зачёт — лучший круг).
- **Сход** (A6) — не засчитан, если вне коридора больше 2 % пройденного на отрезке старт → финиш или один выход
  длиннее 500 м; ровно 2 % и ровно 500 м — засчитано.
- **Отказ с причиной:** нет старта, нет финиша, обратное направление, пропуск участка, разрыв записи GPS, сход с
  коридора, вне окна, запись слишком редкая (точка раз в 30–60 с на извилистой дороге — путь между точками не
  проверить). Одиночные «прыжки» GPS отбрасываются.

## Участие и результат (эпик «Результат гонки», слайс 03)

Решения A5, A7, A8, A12–A14; панель «Результаты» — слайс 05.

**Экраны приложения (слайс 04):** блок «Ваше участие» на карточке гонки — «Участвовать» (гость — вход с возвратом к
гонке), «Загрузить заезд» (файл → попытка), «Выбрать свой заезд» (отдельный экран за входом), «Ваше время», «Проверка
трека» / «Место появится после проверки.» (место появляется тихо, опрос раз в 3 с), попытки со статусом и причиной,
«Отменить участие» с подтверждением; предварительная таблица «Результаты» на карточке (имя — с согласием райдера, иначе «Участник»; своя строка — «Вы»,
ничья «=N»). Отдельного экрана результата нет (D2), карточка соперника — вместе со спорами (слайс 06) или именами
(D1).

- **Заявка** — «Участвовать» на опубликованной гонке с коридором, пока окно не закрыто (до и во время окна). Одна
  заявка на гонку. **Отменить участие** можно, пока окно открыто; результат уходит из зачёта, места других
  пересчитываются, заявиться снова нельзя (A13).
- **Фиксация (V-12):** с первой заявки коридор, окно (оба конца — продлить нельзя, A14), класс и покрытия гонки не
  меняются; название, описание и плановая дата протокола — как раньше. Ворота линейного маршрута не должны
  пересекаться: старт и финиш дальше двух радиусов ворот, иначе — круговой маршрут или меньший допуск.
- **Попытки** — каждый заезд заявленного райдера в окне и рядом с маршрутом проверяется автоматически (импорт
  Garmin/Wahoo и ручная загрузка), в том числе заезд, загруженный до заявки. Явно — «Загрузить в гонку» (файл →
  попытка, когда файл разобран) и «Выбрать свой заезд». Загрузить можно до закрытия окна + 24 ч (по времени приёма
  файла сервером, A5). До 30 попыток на заявку.
- **Скрытые несовпадения (A8):** автоматическая попытка без полного проезда старт → финиш (поездка мимо гонки) или
  с неправдоподобным треком не показывается как отказ. Явная попытка видна всегда, с причиной.
- **Лучшая попытка** — засчитанная с минимальным временем; результат предварительный до публикации протокола.
- **Места** — «1, =2, =2, 4»: равенство до секунды, следующее место пропускает разделённые. В таблице гонки —
  имя райдера, если он задал его и разрешил показ ([profile.md](profile.md)), иначе «Участник»; своя строка — «Вы».
- **Не удалось проверить** — проверка не прошла после повторов: команда платформы видит такие попытки в панели.

## Зачёт: Verified/START, группы, сезон (решения спайка 07–08, слайсы 07–08)

Решения автора 2026-10-27, `docs/tasks/2026-10-27-race-results/spike-07-08.md` §5.

- **Verified** — анкета (пол, год рождения, вес, рост, FTP по желанию) и пульс в треке: место в группе, очки
  сезона, спор. Заезд без пульса — вне зачёта. **START** — время без места и очков. Повысить START до Verified можно,
  пока открыто окно; понизить нельзя.
- **Группы зачёта** — пол × возраст: М/Ж × до 39, 40–49, 50+ (возраст на 31 декабря). Можно заявиться в более
  молодую группу своего пола. Пол и год рождения после первой Verified-заявки меняет только команда платформы.
- **Уточнения 07a** (`docs/tasks/2026-10-27-race-results-07-tiers-clusters/task.md` §8): заявка без выбора уровня
  (старое приложение) в новой гонке — START; в гонках до слайса 07 (схема `overall`) уровень не выбирается — все
  заявки как Verified в одной группе, правило пульса не действует. Повторная заявка без уровня ничего не меняет;
  группа Verified-заявки фиксируется (сменить — нельзя). Время START и Verified без пульса — в таблице
  **«Финишёры»** без места (и после публикации протокола: в протокол они не входят). Спор подаёт и оспаривает только
  Verified с местом в той же группе. Заезд, импортированный из Garmin/Wahoo, — «с пульсом» по признаку тренировки
  (рядов датчиков у агрегатора нет; решение автора 2026-10-27).
- **Рейтинг сезона** — очки за место (100, 85, 75, 67, 60, 54, 49, 45, 41, 38, далее −2, минимум 1), ничья «=N» —
  очки места N. В зачёт идут лучшие `M − ⌊M/3⌋` гонок, отменённые в M не входят. DQ даёт 0 и не выбрасывается.
  Таблицы — класс × группа.
- **Рейтинг сезона, сервер (race-results-08a):** в зачёт — только строки опубликованных протоколов (Verified с местом
  и DQ); гонка без строк в группе всё равно входит в M этой группы; ничья в сезоне разбивается по числу лучших мест
  среди засчитанных гонок («=2» — 2-е, DQ без места), не разбилась — общее «=N»; минимума участия нет. Таблица
  обновляется регламентом сервера — до ~1 минуты после публикации протокола или пересчёта. API: публичные сводка и
  таблица сезона, свои строки (`/me`), панель — с версией формулы и признаком «ждёт пересчёта». Экраны — 08b/08c.
