# Онбординг после входа: опрос и геопозиция

Решения автора и оркестратора по слайсу 4 (`docs/tasks/2026-10-25-onboarding-04-survey-geo/task.md`, §8.2), 2026-10-25.
Прототипа `key-onboarding` в репозитории нет — варианты и тексты утверждены здесь.

## Порядок

Первый вход в аккаунт (автовход после подтверждения e-mail или вход по паролю) → «Что вас привело?» → «Покажем, что
рядом» → «Подключите устройство» (`tracks-and-devices.md`) → Главная. «E-mail подтверждён» подсказывает: «Дальше — короткий опрос.»

## Опрос «Что вас привело?»

- **Обязательный** (Q3): без ответа вкладки недоступны; «Пропустить» нет.
- **Несколько ответов, минимум один** (Q2), «Продолжить» выключена до первого выбора.
- **Варианты** (Q1), коды — в контракте `RideReason`, только добавляются в конец:

  | Код | Текст |
  |---|---|
  | `races` | Гонки и результаты |
  | `group_rides` | Кофе-райды и катание в компании |
  | `routes` | Новые маршруты |
  | `calendar` | Календарь стартов |
  | `exploring` | Пока просто смотрю |

  Без «Другое» со свободным текстом (ПДн, модерация).
- **Уже зарегистрированные аккаунты** тоже проходят опрос при следующем запуске (Q4).
- Ответ хранится на сервере в профиле; другое устройство повторно не спрашивает. Изменить ответ из профиля — не в
  этом слайсе (Q10).
- Тексты (Q7): кикер «Знакомство»; «Отметьте всё, что подходит. Ответ поможет сделать «Покатим» удобнее для вас.»;
  ошибка — «Не удалось сохранить ответ. Повторите.»

## Геопозиция

- Один pre-permission экран «Покажем, что рядом»: «Разрешить» — системный диалог, «Не сейчас» — без него; любой
  исход ведёт на Главную, приложение не блокируется.
- Показывается один раз на устройство и только если решение ещё не принято в ОС/браузере; **автоматически больше не
  предлагается** (Q5): дальше — в момент использования «рядом» (баннер «в настройки» при отказе — с фичей «рядом»).
- **Координаты не читаются и не хранятся**, статус разрешения на сервер не уходит (Q6).
- Точность — выбор пользователя в системном диалоге (Q8), приблизительная по умолчанию не навязывается.
- Системная строка iOS: «Геопозиция нужна, чтобы показать заезды, маршруты и старты рядом с вами. Покатим её не
  записывает и не хранит.» Always/фон/Motion не запрашиваются.
- **Перед публикацией в сторах** (R6): шаг остаётся только при живой фиче «рядом», иначе выключается
  (`LOCATION_STEP_ENABLED`, release-чеклист `docs/runbooks/deploy.md`).
