# social-buttons — кнопка «Свои» называет действие (task2)

## Проблема

Кнопка связи показывала статус «В своих», а после нажатия — действие «В свои» (основная, чёрная). Строка убранного
райдера на экране «Свои» выглядела как прежде. Ширина кнопки менялась с подписью — текст слева переносился.

## Решение

- Кнопка всегда называет действие. Профиль райдера и карточка строки результата: «В свои» (основная) / «Убрать из
  своих» (вторичная). Экран «Свои»: «Убрать» (вторичная) / «Вернуть» (основная). Обоснование: вторичная — для
  обратимого, «тихого» действия над уже связанным (K1, без подтверждения), основная — для добавления / возврата;
  «Вернуть» на экране «Свои» читается как отмена только что сделанного, «В свои» там было бы двусмысленно с
  исходным состоянием. На экране «Свои» контекст списка делает «Убрать» однозначным; на профиле нужен объект — «из своих».
- Строка убранного: остаётся до ухода с экрана; имя — `text.secondary`, аватар — `layout.mutedOpacity` (0,45),
  подпись строки («Вместе…» / «Добавлены вами») не меняется — высота строки та же, соседи не прыгают; статус
  «Убраны из своих» — в имени ссылки строки для скринридера, зрячему — приглушение и кнопка «Вернуть». Зачёркивания
  нет: оно читается как необратимое удаление и ухудшает читаемость имени.
- Ширина: `Button.reserveLabels` (`@rkarakulov/ui` 0.8.0, app-foundation #27) — по самой длинной подписи, индикатор
  загрузки — поверх прозрачной подписи.
- a11y: `Button.accessibilityLabel` — «Убрать из своих: <имя>», «Вернуть в свои: <имя>», «В свои: <имя>» (видимая
  подпись — начало имени). Карточка строки результата — без имени (A12), имя кнопки = подпись.
