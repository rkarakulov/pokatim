# «Свои»: кнопка называет действие, убранная строка приглушена, ширина кнопки постоянна

## Что изменилось

- **Профиль райдера и карточка строки результата гонки:** «В свои» (основная) / «Убрать из своих» (вторичная)
  вместо статуса «В своих». Гость — «В свои» → вход, как было.
- **Экран «Свои»:** «Убрать» (вторичная) / «Вернуть» (основная). Убранная строка остаётся до ухода с экрана
  приглушённой: имя — `text.secondary`, аватар — `layout.mutedOpacity` (0,45). Подпись строки не меняется — высота
  строки та же. Статус «Убраны из своих» входит в a11y-имя ссылки строки.
- **Ширина кнопки** — по самой длинной подписи своих состояний: новый `Button.reserveLabels` из `@rkarakulov/ui`
  0.8.0 (app-foundation #27, релиз #28). Во время загрузки индикатор рисуется поверх прозрачной подписи, поэтому
  ширина не меняется и при загрузке.
- **a11y:** `Button.accessibilityLabel` — «Убрать из своих: <имя>», «Вернуть в свои: <имя>», «В свои: <имя>».
  Видимая подпись стоит в начале имени (label-in-name). Карточка результата — без имени (A12).
- **Конфигурация:** каталог `@rkarakulov/*` 0.7.1 → 0.8.0 (`pnpm-workspace.yaml`, fixed-группа). По коду изменился
  только `ui` (`Button`); Security checklist — в task.md. Новый токен `layout.mutedOpacity` в `@pokatim/design-tokens`.
- Документация: `docs/product/social.md` (K6), `profile.md`, `.claude/rules/pokatim-app.md`.

## Почему такие подписи

- Кнопка всегда описывает действие, которое произойдёт по нажатию. Уже связанного убирают вторичной кнопкой: это
  тихое и обратимое действие (K1). Добавляют и возвращают основной кнопкой.
- На экране «Свои» контекст списка делает «Убрать» однозначным. «Вернуть» читается как отмена только что сделанного.
- Зачёркивания нет: оно выглядит как необратимое удаление и мешает читать имя.
