возврат гостя к гонке после входа.

# 2. Goal

Ручная проверка dev (`docs/qa/2026-10-27-dev-smoke.md` в scratchpad сессии смоука) нашла баги приложения. Блокеров нет.
Задача — исправить каждый минимально, с тестом, который падает без исправления. Карта (B2–B4) и панель (B11, B12,
B14–B18) — другие сессии.

Путь: fast path (пачка локальных багфиксов, контракты API и сервер не меняются). Human gate: автор разрешил
автономную работу.

# 8. Acceptance Criteria

- AC1: `/<неизвестный путь>` — «Страница не найдена» по-русски, «На главную» ведёт на `/`; `/_sitemap` — тот же экран;
  `/ui-kit` в production — тот же экран.
- AC2: вошедший на гонке с коридором до ответа сессии видит скелетон блока участия, а не пустое место.
- AC3: срок загрузки `2026-11-09T21:00:00Z` — «до 9 ноября, 23:59».
- AC4: отмена участия без результата — текст без «результат уйдёт из зачёта»; с результатом — прежний.
- AC5: пустое «Выбрать свой заезд» — кнопка «Загрузить заезд», после загрузки — попытка `{ uploadId }` и назад.
- AC6: райд без `organizerName` — без строки организатора; с именем — «Организатор: Алексей».
- AC7: стопка идущих — квадраты с иконкой, подпись «идут N из M» прежняя.
- AC8: повторный фокус в течение 10 с после ответа не перезапрашивает участие.
- AC9: тексты B19 с точкой.
- AC10: колонка контента на широком экране не шире `layout.contentMaxWidth`.
- AC11: гость с признаком — запуск без `POST /v1/auth/session/refresh`; без признака — refresh как раньше;
  незавершённый выход — отзыв повторяется при любом признаке; вход и poll снимают признак, подтверждённый выход и 401 —
  ставят.
- AC12: гость → «Участвовать» → вход → снова карточка гонки.

## 8.1 Decisions

- D-B9: `docs/product/rides.md` (ответы автора): «пусто → «Организатор»». На карточке подпись живёт в кикере героя
  («ОРГАНИЗАТОР: АЛЕКСЕЙ»); без имени остаётся слово-заголовок без значения — смоук принял его за пустое поле.
  Выбор — строки нет; ответ автора в `rides.md` уточнён (в отметке «Вы организатор» и шапке «Кофе-райд» роль уже видна).
- D-B19: `profile.show.hint` — только точка в конце, смысл не меняется. Правило ключа («сменили текст — поднять
  `PUBLIC_NAME_CONSENT_VERSION`») исполняем буквально: версия `2026-10-27`. Версия только записывается в журнал
  согласий, повторного согласия не требует.
- D-B21: признак — не токен и не данные сессии (как `pokatim.signOutPending`); читается и пишется только под Web Lock
  в операциях восстановления, обновления access, входа/poll и выхода. Только отрицательный: положительный («была
  сессия») записывал бы след входа в хранилище, а тесты F5b держат хранилища пустыми после входа.
- D-return: сценарий «гость → Участвовать → вход → гонка» в тесте проходит (как и у райдов). На смоуке вход, вероятно,
  был в другой вкладке: путь живёт в `sessionStorage` вкладки (правило `pokatim-app.md`). Код не меняется, тест
  добавлен.
