### [HIGH] При ожидании сети шапка остаётся без сообщения и повтора

- **file:** apps/admin/src/features/seasons/SeasonScreen.tsx
- **location:** 60–67, 80–91
- **problem:** При `seasons.fetchStatus === 'paused'` без данных заголовок заменяется на «Сезоны», даты отсутствуют, а баннер не показывается: его условие проверяет только `seasons.isError`. Приостановленный запрос может иметь `status: 'pending'`, поэтому эта ветка не сообщает об отсутствии соединения и не предлагает повторить загрузку шапки.
- **why_it_matters:** Обработка ошибки шапки исправлена не полностью. Нарушен AGENTS.md §4.12: каждый блок асинхронных данных при отсутствии сети должен показывать «Нет соединения» с повтором. Если рейтинг уже закэширован, пользователь видит таблицу под общим заголовком без объяснения отсутствующих названия и дат.
- **evidence:** Строка 63 явно обрабатывает `fetchStatus === 'paused'` только как условие текстовой заглушки; строка 81 создаёт баннер исключительно при `seasons.isError`. Общий `ErrorState` в `apps/admin/src/ui/states.tsx` поддерживает `offline`, а сводка этого экрана и `DataTable` уже учитывают `paused`.
- **recommended_fix:** Для шапки без данных обрабатывать `paused` вместе с ошибкой: показывать сообщение «Нет соединения» и повтор `seasons.refetch()`, сохраняя доступный рейтинг. Добавить тест с приостановленным запросом сезонов и доступными данными рейтинга.
