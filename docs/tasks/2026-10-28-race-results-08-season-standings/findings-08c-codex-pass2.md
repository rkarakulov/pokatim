### [HIGH] Ошибки загрузки сезона скрывают блок профиля без возможности повтора
- **file:** apps/app/src/features/standings/profile-season-block.tsx
- **location:** ProfileSeasonBlock, строки 92–95
- **problem:** Блок получает сезон через `useHeaderSeason()`, который возвращает `null` при ошибке `getCurrentSeason`, включая ошибку фонового обновления с сохранёнными данными. Поэтому первая ошибка скрывается, а при обновлении уже показанный рейтинг исчезает. Дополнительно ранний выход при `me.data.items.length === 0` скрывает ошибку обновления `/me`, если предыдущий успешный ответ был пустым.
- **why_it_matters:** Пользователь не может отличить отсутствие результатов от сбоя загрузки и повторить запрос. Исчезновение показанных данных и отсутствие ошибки с повтором нарушают AGENTS.md §4.12.
- **evidence:** `features/races/queries.ts:173`: `if (!current.isSuccess) return null`; `ProfileSeasonBlock`: `if (!season) return null` и проверка пустых `items` выполняются до `SeasonSection`, где находится единственный `TabFailure`. Ошибки запросов определения сезона вообще не передаются этому компоненту.
- **recommended_fix:** Предоставить блоку состояние запросов определения сезона вместе с сохранёнными данными. Первую загрузку показывать скелетоном, ошибку — баннером с повтором; при ошибке обновления сохранять сезон и рейтинг. Скрывать блок по пустому `/me` только при отсутствии ошибки. Добавить тесты отказа определения сезона, отказа его обновления после показанного рейтинга и отказа обновления `/me` после пустого ответа.

Исправления предыдущего прохода подтверждены: ошибка `/me` отображается на экране сезона, счётчики берутся из первой страницы таблицы.
