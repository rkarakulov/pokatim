### [HIGH] Ошибка `/me` скрыта на экране сезона
- **file:** apps/app/src/features/standings/season-standings.tsx
- **location:** SeasonStandings, строки 180–186, 203–217
- **problem:** Ошибка запроса своих строк лишь снимает ожидание через `meSettled`. После этого `AsyncContent` получает состояние сводки, а отдельного сообщения об ошибке `/me` и действия повтора нет. Ошибка фонового обновления `/me` также скрывается.
- **why_it_matters:** При успешной публичной загрузке и отказе `/me` вошедший пользователь видит таблицу без «Вы», как будто он не участвовал. Причина не показана, повтор запроса недоступен рядом с блоком. Это нарушает AGENTS.md §4.12: ошибки каждого блока должны отображаться с повтором, при обновлении данные должны сохраняться.
- **evidence:** `me.isError` используется в `meSettled`, но `query={state}` передаёт `summary`. В `StandingsTables` единственный `TabFailure` получает публичный `query`, а `useSnapshotSync` сразу выходит при отсутствии `me.computedAt`.
- **recommended_fix:** Для вошедшего пользователя показывать отдельный баннер ошибки `/me` с повтором через `me.refetch`, сохраняя публичную таблицу и имеющиеся данные. Добавить тесты первой ошибки `/me` и ошибки его обновления при успешных публичных запросах.

### [MEDIUM] Счётчики берутся из другого снимка, чем строки таблицы
- **file:** apps/app/src/features/standings/season-standings.tsx
- **location:** StandingsTables, строки 113–120
- **problem:** Заметка «лучшие N из M» и число участников используют `table` из `summary.tables`, хотя строки загружаются отдельным запросом и имеют собственные `racesTotal`, `racesCounted`, `riders` и `computedAt`.
- **why_it_matters:** Сводка и таблица кэшируются независимо. После пересчёта экран может показывать новые места и очки с прежней формулой отбора и прежним числом участников. Для предусмотренного RC-12 случая исчезнувшей таблицы подпись продолжает утверждать, что участники есть, одновременно с сообщением об их отсутствии.
- **evidence:** `table = pickTable(summary.tables, me.data, picked)`, тогда как `first = query.data?.pages[0]`. Подписи читают `table.racesTotal`, `table.racesCounted`, `table.riders`; соответствующие поля `first` не используются. Тест RC-12 возвращает нулевые счётчики таблицы при непустой сводке, но проверяет только пустое состояние.
- **recommended_fix:** После получения первой страницы брать счётчики из неё; сводку использовать для вариантов переключателей и предварительного состояния. Добавить тест с различающимися счётчиками сводки и таблицы, включая RC-12.
