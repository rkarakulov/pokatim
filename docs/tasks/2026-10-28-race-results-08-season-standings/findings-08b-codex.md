### [HIGH] Ошибка обновления сводки скрывается при наличии данных
- **file:** apps/admin/src/features/seasons/SeasonScreen.tsx
- **location:** 82–105
- **problem:** При наличии `summary.data` компонент всегда показывает сводку, игнорируя `summary.isError`. Ошибка повторного запроса не сопровождается баннером и кнопкой повтора.
- **why_it_matters:** Пользователь продолжает видеть старые время пересчёта и статус «Актуален» без уведомления о сбое. Нарушен AGENTS.md §4.12: ошибка обновления должна сохранять данные и показывать баннер с повтором.
- **evidence:** Ветка `if (data)` предшествует обработке `summary.isError`. `DataTable` получает состояние другого запроса — таблицы; ошибку сводки он показать не может. Повторный запрос сводки, например, запускается через `invalidateQueries` в `SeasonStandingsTable.loadMore`.
- **recommended_fix:** Над сохранённой сводкой показывать существующий `Banner` с повтором `summary.refetch()`. Добавить тест: успешная сводка → ошибка её обновления → данные остаются, баннер виден, повтор восстанавливает состояние.

### [HIGH] Ошибки загрузки названия и дат сезона полностью игнорируются
- **file:** apps/admin/src/features/seasons/SeasonScreen.tsx
- **location:** 46–48, 59–66
- **problem:** Запрос `seasonsQuery` используется для шапки, но его ошибки и состояние ожидания сети нигде не обрабатываются. Если `listSeasons()` завершается ошибкой, а сводка рейтинга успешно загружается, экран показывает общее название «Сезоны» без дат и без возможности повторить загрузку шапки.
- **why_it_matters:** Обязательные название и даты сезона отсутствуют, а пользователь не получает объяснения и действия для восстановления. Нарушены §11.2 задачи и AGENTS.md §4.12 об обработке ошибок каждого блока асинхронных данных.
- **evidence:** Из `seasons` читается только `data?.find(...)`; все ветки ошибок и кнопки повтора относятся исключительно к `summary`. При `seasons.isError` используется fallback `t('admin.seasons.title')`.
- **recommended_fix:** Добавить обработку ошибки `seasonsQuery` с повтором именно этого запроса; при ошибке обновления сохранять шапку и показывать баннер. Проверить тестами независимый отказ `listSeasons()` при успешной загрузке рейтинга и восстановление по кнопке повтора.
