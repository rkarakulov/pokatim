# panel-race-map — карта гонки с коридором и скраббингом в панели

Уровень: task2. Ветка `claude/panel-race-corridor-map-172b1b` от `origin/develop`. Follow-up из `docs/product/routes.md`
(«карта гонки (коридор) в панели»). Связано: routes-05 (`RouteMap`, `RouteReadyView`, `ElevationProfile`,
`createScrubStore`), race-results-01 (`CorridorField`), maps-01 приложения (слой коридора `@pokatim/route-view`).

## 1. Title

Страница гонки панели: блок «Карта гонки» — линия маршрута, коридор ±`widthM`, цифры и профиль высоты со скраббингом.

## 2. Goal

Организатор на странице гонки с коридором видит маршрут на подложке с коридором допуска так же, как райдер в
приложении, и рельеф со связанным скраббингом (маркер на карте ↔ курсор профиля). Сейчас в `RaceEditor` есть только
компактное превью маршрута в поле «Эталонный коридор».

## 3. Scope

- `RouteMap` (`features/maps`): необязательный `corridorWidthM` — с ним слой коридора `routeLayers(PANEL_MAP_THEME,
  widthM, …)` (`CORRIDOR_LAYER_ID`), без него — как сейчас (без коридора); смена допуска пересоздаёт карту.
- `RouteLine` / `RouteReadyView` (`features/routes`): пробрасывают `corridor` (`widthM`), подпись карты с коридором;
  `RouteReadyView` — уровень заголовков (`headingLevel`, по умолчанию 2) для вложения в блок гонки.
- `features/races/RaceCorridorMap.tsx` — блок «Карта гонки» под формой `RaceEditor` у сохранённой гонки с коридором
  (любой статус): данные — `routeQuery(corridor.route.id)` (тот же ключ, что у превью и дистанции). Состояния: первая
  загрузка — скелетон карты; ошибка без данных — `ErrorState` с повтором («Нет соединения» / «Не удалось загрузить»);
  ошибка обновления при данных — баннер с повтором над блоком; маршрут не `ready` — блока нет. Под картой —
  «Коридор: ±N м от маршрута · Открыть маршрут» (новая вкладка). Стор скраббинга — на экземпляр блока.
- Без env стиля — `LinePreview` (коридор текстом под линией).
- i18n: `admin.races.map.*`. Документация: `pokatim-web.md`, `admin-panel.md`, `routes.md` (follow-up снят).
- e2e `races.spec.ts`: после создания гонки с коридором — карта гонки видна.

## 4. Out of Scope

- Контракты и API (данные уже есть: `PanelRace.corridor`, `PanelRoute.line/elevation`).
- Скраббинг в компактной карте поля коридора (остаётся follow-up `routes.md`).
- Изменения CSP (та же карта и тот же стиль, что у routes-05).

## 8.2 Deviations from spec / решения без прототипа

| # | Вопрос | Решение |
|---|---|---|
| D1 | Какой коридор показывать — сохранённый или из несохранённой формы | **Сохранённый** (`race.corridor`): блок показывает то, что видят райдеры; несохранённый выбор показывает компактное превью поля (как раньше). Новая гонка — блока нет до создания. |
| D2 | Где блок | Под формой, отдельной секцией «Карта гонки» в той же колонке: форма не смешивается с интерактивной картой (кнопки карты не в `<form>`). |
| D3 | Цифры маршрута | Тот же `RouteReadyView` целиком (карта, цифры, профиль): время в пути — по покрытиям гонки (`race.surfaces`). Копий блока нет. |
| D4 | Толщина линии с коридором | Как на странице маршрута панели — `ROUTE_CATALOG_LINE_WIDTH` (5 px) поверх полосы коридора (мин. `CORRIDOR_MIN_WIDTH_PX`); цвет и прозрачность коридора — `themes.panel.map.corridor`, `CORRIDOR_OPACITY`, как в приложении. |
| D5 | Компактное превью в поле при показанном блоке | Остаётся: оно — отклик на выбор в поле (и ссылка «Открыть маршрут»); поведение поля не меняется. |
| D7 | Ошибка обновления маршрута сохранённого коридора | Баннер у превью поля и у блока — каждый у своего содержимого (выбор в поле может отличаться от сохранённого коридора); повтор любого перечитывает общий запрос. Принято по ревью pass 1 (LOW-2). |
| D6 | Ошибка 404 маршрута коридора | Как прочие ошибки — `ErrorState` с повтором (сервер не даёт удалить маршрут гонки; отдельного текста нет). |

## 9. Acceptance Criteria

1. Гонка (черновик и опубликованная) с коридором: под формой секция «Карта гонки» — карта с подписью «Карта гонки …
   коридор ±N м…», цифры, профиль `role="slider"`; без коридора и у новой гонки — секции нет.
2. На `load` карты добавлены слои коридора (ширина по `widthM`) и линии; карта маршрута routes-05 — по-прежнему без
   коридора.
3. Скраббинг: клавиши на профиле двигают маркер карты (стор блока).
4. Состояния: скелетон, ошибка с повтором, баннер ошибки обновления; без env стиля — `LinePreview` и текст коридора.
5. `pnpm check` зелёный, `ADMIN_BASE=/admin/ pnpm --filter @pokatim/admin build` проходит, смоук не сломан.
