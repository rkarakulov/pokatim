### [HIGH] Ошибка загрузки права жалобы молча скрывает «Пожаловаться»
- **file:** apps/app/src/features/routes/route-detail.tsx
- **location:** 181–205 (`RouteReportAction`)
- **problem:** Компонент проверяет только `viewer.data`. При первой загрузке, сетевой ошибке или 5xx без данных возвращается `null`. При ошибке обновления сохранённых данных предупреждения тоже нет.
- **why_it_matters:** Вошедший райдер открывает одобренный чужой маршрут, но после сбоя `GET /v1/routes/:id/me` действие жалобы исчезает без объяснения и видимого повтора. Нарушен AGENTS.md §4.12: асинхронный блок должен показывать скелетон, ошибку с повтором и баннер при ошибке обновления.
- **evidence:** Строка 197 — `if (!viewer.data?.canReport) return null`; `viewer.isError`, `viewer.error` и состояние загрузки нигде в компоненте не обрабатываются. Подключение `viewer.refetch` к pull-to-refresh не показывает пользователю причину исчезновения действия. Новые тесты карточки проверяют успешные ответы, но не отказ запроса `me`.
- **recommended_fix:** Для вошедшего зрителя маршрута райдера обработать загрузку и ошибки блока через `AsyncContent` либо существующие компоненты состояний: скелетон, ошибка с «Повторить», при обновлении — прежние данные и баннер. Гостю блок не показывать. Добавить тесты первой загрузки, ошибки без данных и ошибки обновления.

### [HIGH] Запрос названия на экране жалобы не имеет состояния ошибки и повтора
- **file:** apps/app/src/features/routes/route-report.tsx
- **location:** 148–153, 176–184
- **problem:** Экран выполняет два независимых запроса, но `AsyncContent` получает только `viewer`. Для `route` обрабатывается исключительно `NOT_FOUND`; загрузка, сеть и 5xx приводят к отсутствию названия без сообщения.
- **why_it_matters:** При успешном `me` и неуспешном запросе карточки пользователь получает форму жалобы без названия маршрута и возможности повторить загрузку этого блока. Нарушен AGENTS.md §4.12.
- **evidence:** Название рендерится через `{route.data ? <Text>…</Text> : null}`. Состояние `route.error` используется только для вычисления `notFound`; повтор `AsyncContent` относится к запросу `viewer`.
- **recommended_fix:** Обработать оба запроса: название показывать со своим скелетоном и ошибкой с повтором либо объединить состояния загрузки экрана. При ошибке обновления сохранять название и показывать баннер. Добавить тест: `me` успешен, карточка отвечает 500, повтор успешно восстанавливает название.
