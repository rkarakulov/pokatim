# app-themes — решения пользователя (2026-10-27)

| # | Вопрос | Варианты | Решение |
|---|---|---|---|
| T1 | Глобальная тема или личный выбор | глобальная / личная | глобальная (личная — возможный follow-up); **заменено 2026-10-29: личная тема райдера — `docs/tasks/2026-10-29-user-theme`, ADR-0021** |
| T2 | Когда тема применяется в приложении | запуск + возврат / только запуск / опрос | **запуск + возврат в приложение**, сразу, без перезапуска |
| T3 | Тёмная пара | по характеру / у всех / одна схема | **по характеру темы**: Хронометр и Навигация — всегда тёмные, остальные — пара по системе |
| T4 | Глубина отличий | только токены / токены + раскладка | **токены + варианты раскладки** |
| T5 | Геометрия базовых компонентов | расширить базу / только проект | **расширить базу app-foundation**, релиз пакетов |
| T6 | Админка | своя тема / вместе с приложением | своя тема `panel` (пользователь допускает общую, если проще) |

Дизайн (слои, слайсы A–D) утверждён пользователем в сессии 2026-10-27.
