# task.md — route-rides-06: граница участка в точке разворота

Уровень: task2. Продолжение route-rides-05 (участки маршрута): два follow-up из §12 05 — продуктовое решение пользователя
«участки на маршрутах туда-обратно нужны» (2026-11-01) и ревью LOW-2 (повторный chainage). Один PR в `develop`, ветка
`feature/route-rides-sections-turnaround`.

## 1. Title

Участки у маршрутов «туда-обратно»: граница в точке разворота; один расчёт chainage в `routeSections`.

## 2. Goal

Сейчас участок, внутри которого маршрут разворачивается по той же дороге, сливается с соседним (движок не засчитывает
повторный вход в ворота старта), и у коротких «туда-обратно» участков нет совсем. Райдеры таких маршрутов не видят
времени по участкам.

## 3. Scope

1. **Разворот → граница.** В `routeSections` (`packages/tracks/src/corridor/sections.ts`) перед слиянием: участок,
   который возвращается к своим воротам или концы которого ближе порога, даёт точку разворота — самую дальнюю от
   возвращаемых ворот вершину до возврата (концы близко без возврата — самую дальнюю от начала). Точка становится
   опорной границей, если она дальше `minTailM` (5 км) от всех опорных границ (старт, финиш, найденные развороты).
   Шаг 10 км и хвост < 5 км раскладываются в каждом плече между опорными границами отдельно. Повторять до
   устойчивости (≤ `maxSections` проходов). Оставшиеся «непроходимые» участки — прежнее слияние.
   Пример: 2 × 17 км → 0–10, 10–17, 17–27, 27–34 км.
2. **Короткие возвраты не дают границу.** Разворот ближе 5 км к опорной границе (шпилька 4 км у старта) — прежнее
   слияние; маршруты без возвратов — границы прежние.
3. **Chainage один раз (LOW-2).** `routeSections` считает chainage линии один раз; подлинии для проверки — внутренним
   `sectionLineOn(line, chainage, …)`. Публичный `sectionLine` — тот же результат.
4. **`ROUTE_SECTIONS_VERSION = 2`.** Новые заезды пишут версию 2.

## 4. Out of Scope

Движок, golden, `CORRIDOR_ENGINE_VERSION`, API, контракты, приложение; бэкфилл участков старых заездов; метки км.

## 5. Architecture Context

- Разбиение — чистая функция, вызывается только из `analyzeSections` (worker, поток разбора). Хранение и сравнение —
  `route_rides.sections.version`, `sectionsOf` сравнивает только одинаковые версию и `fromM`/`toM`.
- Ворота: `corridorGateRadiusM(widthM) = max(widthM, 30)`, порог близости `2R + gateMarginM` (150 м при ширине 50).

## 8. Risks / Assumptions

- `[ASSUMPTION]` Старые заезды с версией 1 не пересчитываются и не сравниваются с версией 2 (заезды есть только на dev,
  бэкфилла нет — как в 05). Участки версии 1 у них остаются видны.
- Участок обратного плеча идёт по той же дороге, что и прямое, в другую сторону. Движок ищет попытку по воротам и
  порядку — проверить `analyzeSections` на синтетическом проезде «туда-обратно»: все участки засчитаны.
- Повторы одного плеча (5 → 0 → 5 → 0 км): участки разных проходов по одной дороге — движок может взять попытку с
  другого прохода; время того же куска дороги, допустимо.

## 9. Acceptance Criteria

1. 2 × 17 км → `[0,10] [10,17] [17,27] [27,34]` км; 2 × 15 км → 4 участка; 2 × 12 км → `[0,12] [12,24]`; дважды
   туда-обратно по 5 км → 4 участка по 5 км. Ни один участок не возвращается к своим воротам.
2. Прежние тесты без возвратов (длины, хвост, петля, 2 × 20 км, предел 30) — те же границы; шпилька 4 км — прежнее
   слияние.
3. `analyzeSections` на проезде 2 × 17 км — все участки засчитаны.
4. Бенч разбиения/сверки в бюджете; тесты, lint, typecheck `@pokatim/tracks` зелёные; полный `pnpm check` и CI зелёные.
