# task.md — push-soft-prompt

## 1. Title

Приложение: подсказка «Включить уведомления» в момент пользы — после «Я иду» на райде и после записи на гонку —
перед системным запросом разрешения push.

## 2. Goal

N5 (`docs/product/notifications.md`): приложение не спрашивает разрешение при запуске, только строкой «Включить
push-уведомления» в центре и в настройках. До строки почти никто не доходит, и push остаются выключенными у тех, кому
они полезнее всего (участник райда — перенос/отмена, участник гонки — изменения и напоминания).

Решение пользователя (2026-10-30): спрашивать в момент, когда польза очевидна, и сначала своей подсказкой. Системный
запрос — только по нажатию «Включить» в подсказке (жест пользователя — Safari/iOS иначе не покажет запрос; Chrome не
переводит сайт в «тихий» режим). «Не сейчас» системный запрос не сжигает.

## 3. Scope

**Продукт:** `docs/product/notifications.md` — N5 переписать (не `[ASSUMPTION]` про «только строка»): при запуске не
спрашиваем; строка в центре и настройках остаётся; плюс контекстная подсказка после «Я иду» и после записи на гонку.

**Приложение (`apps/app`, все платформы: iOS, Android, web/PWA)**
- Компонент `PushSoftPrompt` в `src/features/notifications/` — карточка/`Banner` из `@rkarakulov/ui` (дизайн-система,
  без новых стилей по месту): заголовок и текст по контексту (`ride` | `race`), кнопки «Включить» и «Не сейчас».
  - «Включить» — тот же путь, что строка: `requestPushPermission()` прямо из нажатия → при `granted`
    `registerDevicePush()`; результат — подсказка исчезает (выдано) или превращается в текст отказа (как строка, без
    повторных запросов).
  - «Не сейчас» — скрыть и запомнить отказ на этом устройстве на 30 дней (`PUSH_SOFT_PROMPT_SNOOZE_MS`); хранение —
    как у плашки установки PWA (`install-prompt-state.ts`: web — `localStorage` с try/catch, native — тот же механизм
    хранилища, что уже есть в приложении; посмотреть и переиспользовать, новую зависимость не добавлять).
  - Показывается только если: push поддержан (`usePushSupported()` = `true`), разрешение ещё не спрашивали
    (`status` не `granted` и не `denied` без `canAskAgain`), не отложено «Не сейчас». Иначе — ничего (в т.ч. на
    SSR/первом рендере, пока состояние неизвестно — без мигания).
- Точки показа — под действием сразу после успеха мутации (не при открытии экрана):
  - «Я иду» — `features/rides/going-action.tsx` (`RideRsvpAction`, после `rsvp.mutate('join')` успешно); не после
    «Не иду».
  - Запись на гонку — `features/races/participation/*` (после успешного `useEnterRace`).
  - Одна подсказка за сессию приложения (после показа в одном месте не повторять в другом до перезапуска).
- i18n — `@pokatim/i18n` (ru), ключи `notifications.softPrompt.*`.
- a11y: кнопки с подписями, фокус не прыгает, текст отказа читается скринридером.

**Вне scope:** изменения сервера, контрактов, настроек групп; подсказка в других местах (создание райда и т.п.).

## 4. Acceptance criteria

1. Открытие любого экрана не вызывает системный запрос и не показывает подсказку.
2. После успешного «Я иду» при неспрошенном разрешении и поддержке push — подсказка с контекстом райда; после
   записи на гонку — с контекстом гонки.
3. «Включить» вызывает системный запрос из нажатия; `granted` → регистрация устройства, подсказка исчезает; отказ →
   текст отказа (native — «в настройки», web — где включить в браузере), повторного запроса нет.
4. «Не сейчас» — подсказка исчезает; 30 дней на этом устройстве не показывается; строка в центре/настройках
   продолжает работать.
5. Разрешение уже выдано / отказ навсегда / нет поддержки (в т.ч. iOS Safari вне PWA, сервер без VAPID) — подсказки нет.
6. За одну сессию приложения — не больше одного показа.
7. Ошибка мутации «Я иду» / записи — подсказки нет.
8. Хранилище недоступно (приватный режим) — не падает; «Не сейчас» действует до перезапуска.

## 5. Test matrix

- Unit/Jest (Testing Library): состояние показа (чистая функция по permission + snooze + сессия), `PushSoftPrompt`
  (Включить → request + register; отказ; Не сейчас → запись snooze; snooze в будущем — не показывается), web и native
  моки `push`. Интеграция в `RideRsvpAction` и в участии в гонке: после успеха — есть, после «Не иду»/ошибки — нет.
- Время — fake timers / инъекция clock; TZ Europe/Minsk (jest.config).

  `offerPushSoftPrompt(context, id)` (`push-soft-prompt-store.ts`, без зависимостей UI) из `onSuccess` мутаций; стор в памяти: предложение (`ride:<id>` / `race:<id>`) и
  «показана в этом запуске». Пока место не предложено — компонент ничего не запрашивает.
- `push-soft-prompt-state.ts` — `softPromptVisible` (чистая), `PUSH_SOFT_PROMPT_SNOOZE_MS` = 30 дней, разбор хранилища;
  `push-soft-prompt-storage(.web).ts` — `pokatim.pushSoftPrompt` (native SecureStore через `readJson`, web
  `localStorage` с try/catch).
- Общее со строкой: «Включить» — `usePushPermission().press` (запрос → `registerDevicePush`), текст отказа —
  вынесенный `deniedRow()` из `push-permission-row.tsx`.
- Точки показа: «Я иду» — `RideRsvpAction` (герой Главной — под действием в `ride-hero.tsx`, лента — под строкой в
  `ride-feed.tsx`) и карточка райда `ride-detail.tsx` (своя мутация `useRideRsvp`, тот же «Я иду»); гонка —
  `EnterAction` и `TierPicker` (START и Verified) → подсказка в блоке «Ваше участие» под итогом.
- Решения по ходу: запрос закрыт без ответа (`undetermined`) — подсказка уходит без текста отказа; `denied` (в т.ч.
  Android с `canAskAgain`) — текст отказа, переход в настройки (native) без повторного запроса.
- Доки: N5 в `docs/product/notifications.md`, строка в `.claude/rules/pokatim-app.md`.
- Проверка: `pnpm check` (изолированные Mongo/Redis) — зелёный: app 260 suites / 2464 tests, api 214 files.

### Ревью pass 1 (Claude + Codex, REQUEST CHANGES) — исправлено

1. [HIGH] Подсказка после записи на гонку терялась: `offerPushSoftPrompt` был в `mutate(…, { onSuccess })`, а
   TanStack зовёт его только при живом наблюдателе; `useEntryMutation.onSuccess` ждёт инвалидаций, форма к этому
   времени размонтирована. Теперь предложение — в `onSuccess` хуков до инвалидаций: `useEnterRace` (через
   `onEntered` `useEntryMutation`: заявка стала активной, повышение уровня — нет), `useRideRsvp` (только `join`).
   Регрессионный тест — `race-participation.test.tsx` («форма размонтирована до конца инвалидаций»: `getRaceResults`
   висит, форма ушла, результаты отпущены — подсказка есть); со старой проводкой краснеет (проверено).
2. [MEDIUM] Несколько экземпляров одного id и локальное «спросили/отказ»: фазы в сторе (`idle` → `checking` →
   `offer` | `denied` → `closed`), показ закреплён за первым смонтированным местом (`claimSoftPrompt`), владелец
   размонтирован — `closed` до перезапуска (не успели показать — как не предлагали). Тесты: два места — одна
   подсказка; отказ — «Включить» нигде, запрос один; ушли с места (герой → карточка) — на новом нет.
   `usePushPermission().press` теперь возвращает итоговое состояние (отказ определяется без эффектов).
3. [LOW] «Не иду» закрывает подсказку (`closePushSoftPromptFor` в `useRideRsvp`); размонтирование владельца — п. 2.
4. [LOW] a11y: при переходе в текст отказа — `AccessibilityInfo.announceForAccessibility(текст)`; фокус не переносится
   (требование §3 «фокус не прыгает»: пользователь остаётся у своего действия). Web: баннер отказа без действия —
   `role="alert"` базы, озвучивается при вставке; native — объявление + `accessibilityLiveRegion` баннера.
5. [LOW] Порядок импортов `ride-hero.tsx` — алиасы `@/…` одной группой.
6. [LOW] Лента: «Я иду» в строке → подсказка под строкой (не в слоте действия), одна; отказ мутации — нет. «Не иду»
   в строке ленты не бывает (у участника — текст «Вы идёте»), закрытие по «Не иду» проверено на карточке райда.
