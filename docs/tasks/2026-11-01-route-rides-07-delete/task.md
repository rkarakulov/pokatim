# route-rides-07 — удаление своего заезда по маршруту (task2)

## 1. Title

Райдер удаляет свой заезд по маршруту (follow-up route-rides-01 §4 «Удаление отдельного заезда райдером»,
`docs/product/routes.md` «Что не входит»).

## 2. Goal

Сейчас заезд исчезает только с активностью или аккаунтом. Райдер хочет убрать лишний заезд (ошибочная проверка,
автозаезд, который не нужен) — из своей истории, сравнения, таблицы «Другие» и лучших участков.

## 3. Scope

- API: `POST /v1/routes/:routeId/rides/:rideId/delete` → `204`. AuthGuard, `no-store`, pipe `Uuid`; лимит
  `route-rides-delete:<userId>` 60/ч до любых чтений (404 тратит); маршрут не виден райдеру — `404`; заезд не свой /
  нет / уже удалён — `404 NOT_FOUND`. Любой статус (в том числе идущая проверка: итог её ревизии промахивается).
- Транзакция: `deleteOne { _id, userId, routeId }` + `$pull routeIds` маршрута из планов автопроверки этого райдера
  (`route_ride_auto_plans`, индекс `userId`) — повтор события `tracks.activity-group-created` не воскрешает автозаезд.
  Автозаезд по плану вставляется транзакцией: `markPlannedInsert` (`$inc insertedRides` в документе плана, только пока
  маршрут в нём) + вставка; запись в тот же документ конфликтует с `$pull` из `deleteOwn` — удаление во время прогона
  не воскрешает заезд (ревью Codex pass 1–2).
- Лучшие, сравнение, сводка, «Другие», участки считаются на чтении из живых заездов — пересчёта и снимков нет.
- Клиент `api-client`: `deleteRouteRide(token, routeId, rideId)`.
- Приложение: на экране результата заезда внизу «Удалить заезд» (`TextAction destructive`) → подтверждение
  (текст, «Удалить заезд», «Отмена», ошибка — `Banner`) как удаление «Моего маршрута». Успех (и `404` — уже удалён) —
  деталь и трек из кеша убираются, ветка `['route-rides', routeId]` устаревает, экран — назад к карточке маршрута
  (`router.dismissTo(card)`). `[ASSUMPTION]` тексты и место кнопки.
- Документы: `docs/product/routes.md` (A-раздел заезда, «Что не входит»), `.claude/rules/pokatim-db.md`.

## 4. Out of Scope

- Уборщик сирот — route-rides-08. Удаление из панели, массовое удаление, «корзина».
- Достижения за маршруты уже выданы и не отзываются (как при удалении активности).

## 8. Risks / Assumptions

- `[ASSUMPTION]` `$pull` снимает маршрут из всех живых (≤ 30 суток) планов райдера, не только события удалённого
  заезда: другая свежая активность с тем же маршрутом в незавершённой задаче его не проверит — райдер проверит вручную.
- Ручная проверка той же активности после удаления разрешена — новый заезд (намерение райдера).

## 8.3 Security

Только свои заезды (`userId` в фильтре), чужой — `404` без раскрытия; лимит до чтений; в лог — id без ПДн.

## 9. Acceptance Criteria

1. Свой заезд → `204`; списка, детали (`404`), трека (`404`) больше нет; сводка и лучший — по остальным; повтор → `404`.
2. Чужой заезд, неизвестный, невидимый маршрут → `404`; чужой заезд цел. Без токена — `401`; не-UUID — `400`.
3. 61-й запрос за час → `429`.
4. Удалённый лучший — в «Другие» строка райдера по следующему; единственный — строки нет.
5. Автозаезд удалён → повтор события того же плана — заезд не создан.
6. Приложение: подтверждение, вызов API, переход назад; ошибка — баннер; отмена — без вызова.
7. `pnpm check` зелёный.
