# routes-04d — карточка маршрута: карта на весь экран + шторка (вход для spec)

Пожелание пользователя 2026-10-27 (дословно): «сейчас у нас карта маленькая — давай сделаем, чтоб она занимала больше
места, не будем дублировать под картой название (оно есть вверху уже), и данные под картой компактнее, и текст
„Профиль высоты“ вообще можно убрать, кнопки можно в 1 строку, и панелька сворачиваться умеет — как в айфонах с
чёрточкой вверху блок».

Решения сессии (автономный режим; образец — скриншот пользователя из routes-03 и «Карты» iOS):

| # | Вопрос | Решение |
|---|---|---|
| L1 | Карта | на весь экран под шапкой (`DetailHeader` с названием), интерактивная (одним пальцем — routes-04c) |
| L2 | Шторка | снизу поверх карты, «чёрточка» (grabber) сверху; перетаскивание за чёрточку/шапку шторки и тап по чёрточке; два положения: **развёрнута** (по умолчанию: цифры, чипы, профиль, кнопки; дальше прокрутка — «Гонки на маршруте») и **свёрнута** (чёрточка + строка цифр); карта под шторкой — камера учитывает высоту шторки (padding) |
| L3 | Содержимое | без названия (оно в шапке); компактная строка цифр «Дистанция · Набор · В пути» (подписи мелко, значения крупно — одна строка); чипы; профиль без заголовка «Профиль высоты» (диапазон «201–268 м» и карточка курсора — мелкой строкой над графиком); «Поделиться» и «Скачать GPX» — в одну строку |
| L4 | Доступность | шторка: чёрточка — кнопка «Свернуть»/«Развернуть» (`accessibilityState.expanded`), клавиатура на web (Enter/Space); reduce motion — без анимации перехода |
| L5 | Где | карточка маршрута каталога `/routes/<id>`; «Мой маршрут» — та же раскладка, если без раздувания (иначе follow-up); карта гонки — без изменений |
| L6 | SSR | шторка рендерится развёрнутой на сервере (детерминированно, без `useId` и измерений до монтирования) |

## Дополнение пользователя 2026-10-27 — «Моё местоположение»

«На карте нужен значок такой, куда кликаешь, и он карту к твоим координатам позиционирует».

| # | Вопрос | Решение |
|---|---|---|
| G1 | Что | кнопка «Моё местоположение» в колонке контролов карты (+/−/«в рамку»): одно чтение позиции (foreground, по нажатию), камера — на позицию, точка позиции на карте (отличима от старта/финиша без цвета); без слежения (`watch`) |
| G2 | Приватность (меняет рамку MVP «координаты не читаются до фичи „рядом“» — дополнение ADR-0014 и `pokatim-app.md`) | координаты только в памяти устройства, не отправляются и не хранятся, не логируются; запрос разрешения ОС — при первом нажатии (pre-permission экран уже был в онбординге `(setup)/location`); отказ — баннер/сообщение со ссылкой в настройки ОС; web — Geolocation API (HTTPS) |
| G3 | Где | общий `RouteMap` — карточки маршрута, «Мой маршрут», карта гонки |
| G4 | Платформы | native — `expo-location` (уже в зависимостях, развилка `features/location/*`), web — `navigator.geolocation` в `.web`-файле, вызов синхронно из обработчика нажатия |
