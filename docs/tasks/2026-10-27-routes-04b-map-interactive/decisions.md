# routes-04b — интерактивная карта (вход для spec)

Пожелание пользователя 2026-10-27: «нужно так же уметь карту двигать, увеличивать и уменьшать (зум)». Меняет правило
статичной карты (ADR-0014 RC-4, `pokatim-app.md` «Статичный вид») — ADR-0014 дополняется.

Решения пользователя (2026-10-27, вопрос в сессии routes-03/04):

| # | Вопрос | Решение |
|---|---|---|
| I1 | Жесты на телефоне без поломки прокрутки страницы | **двумя пальцами**: одним пальцем — прокрутка страницы, двумя — перетаскивание и зум карты; кнопки +/− и «вернуть маршрут в рамку»; web — перетаскивание мышью, колесо с Ctrl/⌘ (иначе прокрутка страницы), кнопки |
| I2 | Карта гонки (коридор, свой трек) | **да, тем же слайсом** — общий `RouteMap`, одно поведение; скраббинг на карте гонки — по-прежнему follow-up |

Порядок: после routes-04 (оверлей маркера скраббинга пересчитывает позицию на любое изменение камеры), до routes-05
(панель — та же карта и поведение).
