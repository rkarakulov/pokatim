- **file:** apps/api/src/modules/route-rides/route-ride-auto.processor.ts
- **location:** `run`, строки 85–91; `eventPlan`, строки 109–118
- **problem:** План удаляется через 30 суток миграцией `0046_route_ride_auto_plans`. После удаления `eventPlan` считает событие новым и строит план заново. Возвращается нарушение идемпотентности из AGENTS.md §4.5 и гарантии неизменного плана из task.md §8.2; возможен запрещённый бэкфилл при появлении нового маршрута.

Первый запуск события по двадцати собственным маршрутам с результатом `not_passed` → `{ planned: 20, passed: 0 }`. Затем часы переведены на 31 сутки, удалён истёкший документ плана, как делает TTL, и добавлен новый собственный маршрут. Альтернатива — сохранять устойчивый маркер обработки без TTL. Добавить регрессионный тест повтора после TTL с изменившимся набором маршрутов.
