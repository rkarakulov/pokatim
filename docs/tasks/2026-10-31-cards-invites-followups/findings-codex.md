### [MEDIUM] Карточка старой темы не обновляется автоматически через 10 секунд
- **file:** apps/app/src/features/sharing/card-status.ts
- **location:** 58–76
- **problem:** Если запрос карточки опередит сохранение оптимистично выбранной темы, ответ `ready` старой темы сохранится под новым ключом. Истечение `staleTime` само по себе не запускает запрос, поэтому ограничение этого состояния десятью секундами, заявленное в task.md, не обеспечено.
- **why_it_matters:** Пользователь может продолжать видеть и отправлять карточку прежней темы после успешного сохранения новой, пока не произойдёт отдельный триггер обновления.
- **evidence:** Для `ready` значение `refetchInterval` равно `false`. В `features/appearance/theme-mutation.ts` обработчик `onSuccess` обновляет только профиль, без инвалидации карточек. Проверка установленного `QueryObserver` с такими настройками после истечения `staleTime` дала один запрос и прежний токен.
- **recommended_fix:** После подтверждения сохранения темы инвалидировать запросы статуса карточек; учесть выполняющийся запрос, чтобы его старый ответ не остался окончательным. Добавить тест: карточка старой темы отвечает до завершения сохранения → сохранение завершается → без навигации запрашивается и показывается новая карточка.
