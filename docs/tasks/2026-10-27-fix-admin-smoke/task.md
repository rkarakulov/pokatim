# 3. Scope

| Баг | Причина | Исправление |
|---|---|---|
| B12 — каждый GET дважды | каждый `focus` окна (клик во встроенном браузере, смена вкладки) перезапрашивал данные экрана (`refetchOnWindowFocus` по умолчанию, `staleTime: 0`). Свежая загрузка URL даёт по одному запросу — проверено на dev; `StrictMode` в production-сборке эффекты не дублирует | `createQueryClient`: `refetchOnWindowFocus: false`. `staleTime` остаётся 0: заход на экран — один свежий запрос, так панель узнаёт о погашенной сессии (e2e AC15). Первая версия (`staleTime` 30 с) сломала AC15 — откачена. Попутно дополнены пропуски инвалидации: действия над результатами — список гонок и журнал, выдача роли — журнал |
| B11 — «0,1 км», «0,1 км» в таблице рядов | ячейка рядов ≥ 25 м (`SERIES_MIN_BIN_M`), подпись — `formatKmFromMeters` с 0,1 км | `formatKmPrecise` (0,01 км) в таблице и в подписи перекрестия; столбцы рядов без единого значения (`null` или все `null`) в таблице не выводятся |
| B14 — чек-лист публикации | счётчик у условия «да/нет»; `publishBlockText` брал первую строку; текст строки при нуле — призыв | `window_open` — бейдж «Не готово»; под кнопкой все блокеры через «. »; при нуле — `admin.results.check.<code>.ok` («Сбоев проверки нет») |
| B15 — «32:19» | `formatElapsed` панели опускал часы | всегда `ч:мм:сс`, как `formatElapsed` приложения («0:32:19», «25:01:01») |
| B16 — `origin: auto` «Из импорта» | `auto` — попытка, найденная сервером в треках райдера (любой источник), `explicit` — загружена/выбрана в гонку | `races.attempt.origin.auto` = «Автоматически» — общий ключ; в приложении рядом источник («Garmin · Автоматически»), смысл тот же |
| B17 — описание райда одной строкой | `ReadonlyField` — `white-space: normal` | `ReadonlyField multiline` → `.readonly-field--multiline { white-space: pre-line }` |
| B18 — подписи прилипают к полю выше | у `.radios` `margin: 0`, `.field + .field` не срабатывает между `fieldset` и `.field` | `.form-stack > * + *:not(.form-actions) { margin-top: var(--inset-md) }` на колонке `DecisionPanel` |

Не меняется: контракты, API, StrictMode в `main.tsx` (в production не влияет).

# 4. Acceptance criteria

- AC1 (B12): фокус окна — без второго GET; заход на экран — один свежий запрос (401 погасшей сессии виден, e2e AC15).
- AC2 (B11): подписи дистанции в таблице и перекрестии — «1,00 км»; ряда без данных в таблице нет.
- AC3 (B14): под выключенной кнопкой все блокеры; у `window_open` — «Не готово»; нулевые строки — нейтральный текст.
- AC4 (B15): время в панели — `ч:мм:сс`, и меньше часа, и больше суток.
- AC5 (B16): `origin: auto` — «Автоматически» в панели и приложении.
- AC6 (B17): описание в модерации сохраняет переносы (`pre-line`).
- AC7 (B18): у группы шаблона и поля заметки есть отступ сверху.
