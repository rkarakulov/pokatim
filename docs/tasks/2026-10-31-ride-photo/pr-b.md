## Что сделано

- **Экран карточки-приглашения** (`rides/invite/[id]`): блок «Своё фото» под карточкой — только организатору будущего
  опубликованного райда (`viewer.role === 'organizer' && viewer.canManage` из `me`); состояния `me` — `AsyncContent`
  (скелетон, ошибка с повтором, блок с баннером при ошибке обновления). Запрос `me` на экране — дополнительный к
  публичной карточке (нужен для прав и фото), оставлен. «Добавить своё фото» / «Заменить
  фото» — выбор без обрезки и `PUT` байтами; «Удалить фото» — только при фото. Кнопки заняты на время выбора и запроса
  и выключают друг друга (квота `rides-manage` не тратится на no-op удаление — LOW из findings PR A); на web кнопка не
  занята, пока открыт диалог файла (без `cancel` залипла бы).
- **Удаление после старта и отмены**: «Удалить фото» в карточке райда организатору прошедшего и отменённого райда с
  фото. Скрытый райд — фото не видно и из приложения не удаляется (снимет команда, PR C, или удаление аккаунта). После успеха —
  кеш `me` и инвалидация `['rides']`: лента, Главная, деталь и статус карточек приглашения (`night` с фото — новый
  токен сервера).
- **Ошибки** (`ride-photo-errors.ts`): 415/413/422 `IMAGE_*` (`too_small` — «слишком маленькое или слишком вытянутое»), 429 (занятая
  обработка — «подождите несколько секунд», часовой лимит — «Повторите через …»), 409 `RIDE_INVALID_STATE`, проверка до
  отправки, старый dev-клиент; удаление и сеть — тексты действий с райдом.
- **Общий выбор фото** `features/media/pick-image(.web).ts`: native — `expo-image-picker` (у фото райда без редактора,
  iOS отдаёт совместимое представление HEIC → JPEG; формат на native не проверяется — сигнатуру проверяет сервер), web —
  `expo-document-picker`. Аватар — тонкая обёртка `pick-avatar.ts` (поведение и тесты профиля прежние);
  `load-image-picker.ts` и `image-picker-support.ts` перенесены в `features/media`.
- **Герой ленты «Кофе-райды» и Главной**: `SectionHero` с необязательным `photo` — `expo-image` `cover` по центру,
  декоративное (без озвучивания, на web пустой `alt`), под `PhotoScrim` (новый токен `photoScrimHero` в
  `@pokatim/design-tokens` — без провала: порог контраста на всей высоте, тест; цвет `overlay.scrim`, полосами `View`
  — одинаково на iOS, Android и web), текст и линия — `text.onPhoto`; без фото или при ошибке картинки —
  прежний типографский герой.
