### [HIGH] Запрос прав скрывает загрузку и ошибки блока фото
- **file:** apps/app/src/features/rides/invite/ride-invite-screen.tsx
- **location:** строки 29–31, 64
- **problem:** Из `useRideForViewer` берётся только `.data`. Пока запрос выполняется или завершился ошибкой без данных, блок «Своё фото» отсутствует. Ошибка обновления также нигде не показывается.
- **why_it_matters:** При отказе `/me` организатор не получает управления фото, сообщения об ошибке и возможности повторить запрос. Нарушен AGENTS.md §4.12: первая загрузка требует скелетона, ошибки — сообщения с повтором.
- **evidence:** `const me = useRideForViewer(rideId, valid).data`; при отсутствии `me` переменная `managed` становится `null`, а `{managed ? <RidePhotoSection … /> : null}` ничего не выводит. `CardPanel` обрабатывает собственный запрос статуса карточки и не покрывает ошибки `/me`.
- **recommended_fix:** Сохранить результат запроса целиком и обработать состояния через `AsyncContent`: скелетон на первой загрузке, ошибка с повтором, сохранённый блок с баннером при ошибке обновления. После успешного ответа скрывать управление у пользователей без соответствующих прав. Добавить тесты отказа `/me` и повтора.

### [MEDIUM] После начала или отмены райда нельзя удалить своё фото
- **file:** apps/app/src/features/rides/invite/ride-invite-screen.tsx
- **location:** строки 30–31, 64
- **problem:** Условие `viewer.canManage` скрывает весь блок, включая удаление, для прошедшего, отменённого и скрытого райда.
- **why_it_matters:** Организатор теряет возможность снять ранее загруженное фото через приложение, хотя P2 задачи и раздел «Когда» в `docs/product/rides.md` разрешают удаление в любом статусе.
- **evidence:** `rides.policy.ts` вычисляет `canManage: upcoming && role === 'organizer'`. Единственная кнопка удаления находится внутри `RidePhotoSection`, который отображается только при `canManage`. При этом `RidePhotosService.remove` допускает любой статус. Обычный переход к приглашению из детали тоже ограничен будущими райдами (`canShare = mounted && upcoming`).
- **recommended_fix:** Разделить условия загрузки и удаления: загрузку оставить по `canManage`, удаление предоставить организатору независимо от фазы. Обеспечить доступ к удалению из детали не будущего райда; для скрытого учитывать, что публичный view возвращает `photo: null`. Добавить тесты удаления после отмены и начала райда.
