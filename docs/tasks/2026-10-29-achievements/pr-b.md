## Достижения, PR B: приложение — «Вспышка достижения», блоки в профиле и публичном профиле

Спецификация — `docs/tasks/2026-10-29-achievements/task.md` (A5–A8, AC9–AC13). API — PR A (#103, уже в develop).

### Что сделано
- **«Вспышка достижения»** — `/achievements/flash`, полноэкранный модальный экран поверх вкладок. Хост рядом с
  push-уведомлениями (тот же `ready`) запрашивает список при старте и возврате приложения и открывает вспышку, если
  есть непросмотренные. Вспышки идут по одной, от старых к новым, кнопки «Дальше» / «Закрыть». `seen` уходит в момент
  показа, поэтому закрытие жестом «назад» тоже помечает показанное.
- **«Поделиться»** у гоночных достижений открывает экран сторис результата `/races/story/<raceId>`. У маршрутных и
  райдовых кнопки нет.
- **Экран достижения** `/achievements/[code]`: тот же макет, без «Дальше».
- **Блок «Достижения»:**
  - `/profile` — все достижения, нажатие открывает экран достижения;
  - `/riders/[id]` — только гоночные, данные грузятся только на клиенте;
  - пусто — блока нет; при ошибке — баннер блока с повтором, экран профиля не ломается.
- **Значок «Эмаль»** собран из ролей темы. Размеры — новые токены `layout.badgeGrid` / `layout.badgeHero` и
  `badgeShape` в `@pokatim/design-tokens`.
- **Состояния и анимация.** При «Уменьшить движение» анимации нет. Прямые ссылки до восстановления сессии идут через
  `useSettingsShell`. У вспышки есть скелетон, ошибка и офлайн с повтором.
- **Тексты** `achievements.*` — в `packages/i18n` (ru). В набор иконок добавлены `medal` и `trophy` (SF Symbols и
  Material).
