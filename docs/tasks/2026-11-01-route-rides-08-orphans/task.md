# route-rides-08 — уборщик сирот заездов по маршруту (task2)

## 1. Title

Регламент BullMQ удаляет заезды по маршруту, у которых удалена активность или маршрут (follow-up route-rides-01 RC-1
вариант (b), `docs/product/routes.md` «Что не входит»).

## 2. Goal

Основной путь удаления заездов удалённой активности — событие `tracks.activity-removed` (route-rides-activity-removed),
страховка — фильтр на чтении и удаление сирот в транзакции нового заезда. Остаются: POST, вставивший заезд после
обработки события; сироты до выката подписки; заезды маршрута райдера, удалённого насовсем (события нет). Их
производные данные (время, позиции на линии) живут неопределённо долго.

## 3. Scope

- Очередь `route-rides-maintenance`, `RouteRidesMaintenanceProcessor` (задача `orphans`) и `RouteRidesSchedules`
  (ежедневно 04:23 Минск, upsert; разовый прогон при старте worker, jobId без дублей).
- Скан `route_rides` по `_id` пачками по 500 (`scanRefs`: `_id`, `routeId`, `activityId`), сирота:
  - активности нет (`ActivitySource.liveActivityIds`, ≤ 1000 id) — как фильтр чтения: дубль группы жив, пока есть его
    документ;
  - маршрута нет в `routes` вовсе — новый метод порта `RouteRideRoutes.existingIds` (≤ 1000 id, реюз
    `RoutesRepository.existingIds`). Снятый с публикации, скрытый, не готовый — существуют, заезды остаются (RC-8:
    повторная публикация возвращает историю).
- Удаление `deleteRefs` — `{ _id, routeId, activityId }` в фильтре (признак необратим, повтор — 0).
- Не больше 200 пачек за прогон; хвост — следующим прогоном с курсора Redis `route-rides:orphans:cursor` (TTL 7 сут,
  потеря — скан с начала); конец скана — курсор снят.
- Метрики — итог задачи `{ scanned, deletedActivity, deletedRoute, batches, more }` (BullMQ хранит return value) и
  одна строка лога со счётчиками и длительностью, без id и ПДн.
- Документы: `routes.md`, `pokatim-db.md`, `pokatim-backend.md`.

## 4. Out of Scope

Планы автопроверки (TTL 30 сут), заезды стёртого аккаунта (`RouteRideErasure`), бэкфилл; Prometheus-метрик в проекте нет.

## 8. Risks / Assumptions

- Скан без фильтра — по индексу `_id_`, проекция трёх полей; пачка — два запроса к чужим коллекциям `$in` по `_id`.
- Гонка с новым заездом безопасна: удаляется только заезд с уже удалённой активностью или маршрутом.
- `[ASSUMPTION]` время 04:23 — вне пиков загрузок.

## 8.3 Security

Новых эндпоинтов нет; удаление — только производных данных удалённых объектов; лог без ПДн.

## 9. Acceptance Criteria

1. Заезды удалённой активности и удалённого маршрута удалены; живые, чужие, снятого маршрута, дубля группы — целы.
2. Повторный прогон — 0 удалений; неизвестная задача — ошибка.
3. Предел пачек: `more: true`, курсор в Redis; следующий прогон продолжает с него и снимает курсор.
4. Расписание и разовый прогон при старте (unit).
5. `pnpm check` зелёный.
