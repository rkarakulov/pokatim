## Как проверить свой трек на dev

1. Войти реальным аккаунтом.
2. На карточке гонки с коридором («Осенний гравий Логойска») нажать «Участвовать».
3. Загрузить GPX/FIT заезда по маршруту с временем внутри окна гонки.
4. Дождаться вердикта: на карте появится трек, участки вне коридора будут пунктиром, под картой — строки схода.
