# routes-08 — название маршрута в окне публикации (RC-14, task2)

## 1. Title

Поле «Название» в окне «Опубликовать в каталоге» / «Изменить» маршрута команды в панели.

## 2. Goal

routes-01 RC-14 оставил v1: название каталога = название загрузки (по умолчанию имя файла), в окне публикации не
меняется. Follow-up из `docs/product/routes.md` («Что не входит»): альтернатива RC-14 — поле «Название» в окне
публикации (`RouteTitle`, журнал `changedFields: ['title']`). Готовый маршрут неизменяем по геометрии, не по названию.

## 3. Scope

- `contracts`: `PublishRouteInput.title?: RouteTitle` (3–120, одна строка, trim).
- `api`: `RoutesCatalogAdminService.publish` пишет название в той же транзакции, что каталог; журнал —
  `changedFields` с `title`; `RoutesRepository.setCatalog` — необязательное название.
- `admin`: `RouteCatalogDialog` — поле «Название маршрута» (по умолчанию текущее), ошибки схемы и сервера под полем;
  подпись поля в журнале (`admin.riderRoutes.field.title`).
- Доки: `docs/product/routes.md`, `docs/product/admin-panel.md` при необходимости.

Не входит: маршруты райдеров (A3 — название на проверке и в каталоге не меняется; модерация не трогается),
переименование неопубликованного маршрута команды вне окна публикации, скраббинг в компактной карте панели
(нужно продуктовое решение — у компактной карты нет профиля по A1 routes-05).

## 4. Decisions

- **T1 [ASSUMPTION] `title` необязателен в контракте.** Нет поля — название прежнее (старая вкладка панели после
  выката не получает 400). Панель всегда шлёт поле.
- **T2 Журнал.** Правка опубликованного: `route.catalog_updated`, `changedFields` ⊇ `title`, если название
  изменилось. Первая публикация с новым названием: `route.published`, `details: { changedFields: ['title'] }`
  (без нового — `details: null`, как раньше). Подпись объекта журнала — название после действия. Значения названия в
  `details` не пишутся (как город/покрытие).
- **T3 Повтор с теми же значениями** (включая то же название после trim) — без записи и журнала (RC-2 routes-01).
- **T4 Видимость.** Публичный каталог кэшируется до 60 с (RC-13 routes-01) — новое название видно в течение минуты.
  Имя файла экспорта — название маршрута, меняется вместе с ним. Уведомлений о публикации маршрута команды нет.

## 8. Acceptance Criteria

1. `POST /v1/admin/routes/:id/publish` с `title` у неопубликованного → 200, `title` в `PanelRoute`, в каталоге; журнал
   `route.published` с `changedFields: ['title']`.
2. «Изменить» опубликованного: только название → 200, `route.catalog_updated`, `changedFields: ['title']`, дата
   публикации прежняя; то же название (с пробелами по краям) → без журнала.
3. Без `title` — поведение прежнее; невалидное (`'ab'`, перевод строки, > 120) → 400 с полем `title`.
4. Панель: поле предзаполнено, отправляется с городом и покрытием; ошибка сервера `title` — под полем.
